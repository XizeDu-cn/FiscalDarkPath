## 目前的结论（一页版）

- **C 是硬的**，有四处出处：
  - 2026 年政府工作报告："政府投资基金要带头做耐心资本"；
  - "十五五"纲要："健全'投融管退'机制"；
  - 国办发〔2025〕1号："完善免责认定标准和流程"；
  - 三中全会《决定》："落实'三个区分开来'"。
- **痛点矛盾**：免责条款覆盖率 95%（投中统计，42 份办法），容亏率写到 80%—100%，可管理人还是不敢投、不敢退。业内原话："规则'有没有'早已不是最大痛点……由谁来认定、如何认定"。
- **抄 ResNet 的方式**：重点抄反向传播（信用分配）。
  - 退化问题：层级越多越不敢投；
  - 式（8）的 ∏λ：层层加码与层层打折同出一源；
  - 反向传播要用前向时存下的数据：归责要以当时收到的信息为准，"事后诸葛亮"就等于拿现在的输入去算当时的梯度。
- **闭环**：主链是闭的，比参照文章完整。唯一的断口是"认定兑现"，把审查者放进链条就能补上。
- **包装**：标题用"选择性耐心"，理论用"信用分配"，对策用"国资版程序审慎"。落地设计是"三页一索引一盲审"。
- **方法**：DSGE 不用。主力是"委托代理小模型（ρ = λ^L）→ 文本造证据结构指数 + 多期 DID + 层级深度调节"。纯文字稿只在投《中国财政》这一档时够用。
- **下一步**：先做各地办法证据条款的文本编码。
