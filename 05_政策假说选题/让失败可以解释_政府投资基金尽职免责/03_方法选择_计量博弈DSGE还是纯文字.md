# 方法选择：计量、博弈、DSGE，还是纯文字

> 基准：`CLAUDE.md`。满分 = 目标刊物已发表论文的平均水平。

**结论：DSGE 不用；博弈论用委托代理小模型；计量用"文本造指标 + DID"做主力。纯文字稿只在投《中国财政》这一档时够用。**

## 二、逐个方法看

### 1. 计量：主力

- **A（冲击）**：各地政府投资基金免责、容错办法的出台时间。这些办法分批落地：2020 年前只有 4% 有免责条款，2024 年达到 85%（投中统计）。可以照王学军、冯岩的做法手工收集。
- **C（结果）**：清科私募通或 CVSource 的投资事件，看种子期和早期投资占比、硬科技占比、退出率和持有期。"等得起、退得出"可以拆成两个被解释变量：好项目续投率上升，差项目持有期缩短。
- **B（调节变量，即卖点）**，两个：
  - **证据结构指数**：对各地办法的证据条款做文本编码，看有没有规定决策时点记录、异议记录、不得改写、认定主体、认定程序。
  - **层级深度**：基金结构有几层，即子基金、母基金、省市区多级母基金的层数。数据来自基金业协会公示和工商股权穿透。
- **核心发现可以这样写**：免责政策只在证据结构完备、层级浅的地方有效而且持久，其余地方当年有效、次年反转。这样就把梁蔚萍、周翔翼"当年与次年方向不同"的结果收编进来了。
- "造指标 + DID 调节效应"是《财政研究》《财贸经济》《经济研究》最常见的组合，属于同档平均水平。核心机制只能用代理变量来测，但同档文章也都是这样，不扣分。
- 代价：需要清科或 CVSource 的数据权限。

### 2. 博弈论：委托代理小模型，它就是把 ResNet 公式照抄过来

- 设卷宗要经过 L 层，每一层以概率 1−λ 把它改写成没有信息量的摘要，那么审查者看到原件的概率是 **ρ = λ^L**。这就是 He et al.（2016）式（8）里的 ∏λ，原样抄过来。
- 残差设计相当于让证据通道上的 λ = 1，ρ 不再随层数衰减。
- 管理人有职业顾虑；审查者看不到原件时，就只能按结果追责。由此可以推出三条比较静态：
  - **严格情形**：误罚概率随 L 上升，管理人不敢投、不敢退，这是"责任爆炸"；
  - **宽松情形**：漏罚概率随 L 上升，管理人省掉尽调，这是"责任消失"；
  - **直通结构**：两种情形同时改善，而且改善幅度随层数增大。
- 这三条直接作为计量部分的 H1—H3，其中层级深度就是待检验的调节变量。
- 同档实证文章的理论部分大多是 2—4 页的装饰性推导（参照余明桂那篇的柯布—道格拉斯求导）。这个模型的篇幅够用，而且比平均水平更贴题。
- 如果只想要最便宜的模型稿，可以写演化博弈 + Matlab 仿真，在《证券市场导报》和学报这一档属于平均水平。但演化博弈挂不上"层数"这个卖点，不如委托代理。

### 3. DSGE：不用

- 这个机制发生在组织内部（证据过层、认定），要聚合到宏观层面，中间缺好几个环节；"免责精度"这类参数也没有数据可以校准。
- 同题没有先例，审稿人只会问"为什么要上宏观"。原稿自己也把宏观放在远端扩展。
- 唯一的用处是以后单独写一篇"耐心资本质量与增长"。

### 4. 纯文字稿：看投哪一档

- 《中国财政》《财政监督》《财政科学》、AI 征文：这一档的平均水平就是纯文字，现有材料已经高于平均。
- 《宏观经济管理》：收政策设计稿，不收"理论阐述"，要写成观点鲜明的制度方案。
- 《财政研究》及以上：同档平均都带数据或模型，纯文字不够。

### 附：调查实验（投公共管理刊物时用）

《公共管理学报》在推[行为视角与实验方法](https://gogl.cbpt.cnki.net/portal/journal/portal/client/news/9f4ebfac16ab64176b0aa9fef909ea6d)，干部容错方向也已经有调查实验的先例。

设计：同一套事实做成两种卷宗，一种是"逐层摘要"，另一种是"决策快照 + 每层增量"。再与"项目成功/失败"和"管理人尽职/失职"交叉，测量误罚和漏罚两类错误。被试用在职 MPA 学员。

## 三、组合建议

| 目标 | 组合 | 对应四分类 | 工作量 |
|---|---|---|---|
| 快速占位 | 纯文字 + 模型直观版（只写 ρ = λ^L 和三条推论） | 四 + 三（轻） | 2—4 周 |
| **主力稿（推荐）** | 委托代理模型 → H1—H3 → 文本造"证据结构指数" + 多期 DID + 层级深度调节 | 三 + 二 + 一 | 3—5 个月 |
| 公共管理方向 | 理论框架 + 调查实验 | 四 + 实验 | 2—3 个月 |

最先做文本编码：它既能给纯文字稿提供痛点数字，又是 DID 的调节变量，一份工作两处用。
