## 〇、先回答：“AI×学科交叉”这一类文章的行文套路

### 一句话总纲

**热词 × 手边现成的数据 × 一条标准件流水线 × 一条政策尾巴。**

- 热词负责"新"：生成式AI、算力、大模型、联邦学习、AlphaFold。
- 手边数据负责"能做"：上市/新三板公司、专利、招聘网站、职业大典、税务场景。
- 流水线负责"看起来可靠"。
- 政策尾巴负责"有用"。

四样凑齐就是一篇。缺的往往只有一样东西：一个足够硬的核心发现。

### 八道工序

| 工序 | 在文章里长什么样 | 卖的什么药 |
|---|---|---|
| ① 选题 | 热词 × 现成数据；标题用"A、B与C——来自XX的证据"或"基于XX的发现" | 蹭时效，天然"首次" |
| ② 开头 | 三中/四中全会、"人工智能+"、十五五 → 新一轮科技革命 → 一个痛点（中小企业算力贵、数据孤岛、替代焦虑） | 用"政策重要"顶替"学术上不知道什么" |
| ③ 概念升格 | 给粗糙的变量起大名字：省份哑变量→"公共算力供给"；含"蛋白"二字的专利→"蛋白质创新"；文本相似度→"AI渗透率"；一个常数参数→"共享压力" | 让读者以为测到的是概念本身 |
| ④ 理论装修 | 借一个名牌理论（实物期权、March探索/利用、社会学习理论、马歇尔市场动态）+ 一页纸装饰性模型 + H1/H2a/H2b | 满足"要有理论"；模型的结论其实就是它的假设 |
| ⑤ 贡献三段式 | "现有文献研究了A、B、C，鲜有研究D，本文首次……拓展了三支文献" | 把"填一个空格"包装成"开拓一个方向" |
| ⑥ 实证标准件 | 基准 → 平行趋势图 → 稳健性清单（全进附录）→ 排除替代解释 → 异质性 → 机制 → 进一步分析（质量/扩散/效率三连） | 用"工序齐全"制造"结论可靠"的观感 |
| ⑦ 解读话术 | 系数小："考虑到……具有重要现实意义"；不显著："尚未显现""无助于"；结果为负："J曲线""转型阵痛" | 什么结果都能讲成支持 |
| ⑧ 政策尾巴 | 两三页施政建议，回扣中央文件，多数没被本文检验过 | 决策咨询价值 |

### 这个压缩包里的五篇，就是五种变体

| 论文 | 变体 | 一句话本质 | 招牌动作 |
|---|---|---|---|

| 肖柏高等《生成式AI驱动创新的数量和质量效应——基于诺贝尔化学奖成果AlphaFold的发现》，经济学（季刊）2026-5 | 技术冲击DID型 | 2021年后，医药、化学两个行业里标题或摘要带"蛋白"二字的发明专利，相对别的行业多了约2.5% | 诺奖挂标题（奖是2024年发的，样本截至2023年）；处理组只有2个行业；2021年正赶上新冠疫苗、抗体研发潮；"企业研发效率下降"被讲成"J曲线" |
| 胡涟漪等《人工智能与职业需求》，经济学（季刊）2026-5 | 测度构造型 | 用Sentence-BERT算"AI专利摘要"和"职业大典任务描述"的相似度，叫它"AI渗透率"；再让ChatGPT给动词分类，拆成替代/互补/创造三块，回归51job招聘增长 | 渗透率前十名里有"壁画制作工"，作者拿这张表证明方法"有效"；不显著的替代系数（−0.313，标准误0.277）照样乘进核算，得出"替代效应累计减少岗位100.8万个" |
| 王勇等《算力资源的动态共享：价格形成与政策分析》，经济研究2026-5 | 玩具模型型 | 3家企业、价格等于平均报价的纯交换模型，把两个参数改名"共享动力""共享压力" | 用"需求波动"当动机，模型里却没有任何波动 |
| 温有栋等《联邦学习技术在税收风险管理中的应用构想》，税务研究2024-11 | 应用构想型 | 联邦学习是什么（综述+白皮书）+ 税务数据有孤岛 = 税务应该上联邦学习 | "问题"就是"没用我的技术"；技术栈名词堆满两张图（SpringBoot、Vue、HDFS、Spark、Paillier，外加区块链PoR/PoC共识）；拿纳税信用C/D级当"有风险"标签；验收标准是"和传统稽查结果吻合"；把联邦学习的短板（通信开销大、数据非独立同分布时性能下降）写成了优势 |

上一批9篇（AI与算力宏观）也全是这八道工序的不同组合，这里不重复。

## 一、为什么挑这篇当标本

1. **最标准。** 政策冲击 + 多期DID + 专利 + 机制 + 异质性 + 进一步分析 + 政策建议，八道工序一道不少，是这类文章的"标准件"。
2. **最高规格。** 《经济研究》2026年第8期，说明这条流水线能直通顶刊。
3. **最贴财政学。** JEL分类里有H54（公共投资），处理变量里捆着算力券（财政补贴），本质上是一篇财政支出项目评估。
4. **能和上一批材料串起来。** 它在理论部分把王勇等（2026）那篇"3家企业算力共享模型"当作文献依据引用；合作者Lin William Cong和上一批里的谢丹夏合作过多篇数据经济论文（如Cong, Xie & Zhang 2021, *Management Science*）。

## 二、本质

### 一句话

> **2019年以后有些省份挂牌了政府牵头的"人工智能计算中心"。这些省份的新三板小公司，之后按IPC大口径算的"AI专利"申请（大多数公司一件都没有）比别的省多了一点点：ln(1+专利数)差0.019，只在10%水平显著。**

其余二十多页都是包装。

### 如果不包装，摘要应该长这样

> 2019年后部分省份挂牌了政府主导的公共人工智能计算中心。我们用2016—2023年一直挂牌的5023家新三板公司，比较所在省份建立此类中心前后，公司按IPC分类界定的AI专利申请变化。建中心的省份本来AI专利就多：不加固定效应时差0.076，加上企业和行业×年份固定效应后降到0.02左右，且只在10%水平显著；增长集中在事前AI专利占比高的行业。我们没有任何企业使用公共算力的数据；事件研究中建中心前三期系数均为负、约−0.02，因此无法排除同期针对AI产业的其他地方政策的作用。

同一张表、同一组系数，诚实写出来是一篇两页的研究札记；按流水线写，就是一篇24页的《经济研究》。

## 三、同一件事的两种说法：大白话 ↔ 冠冕堂皇

### 翻译表

| 实际做的事（大白话） | 论文里的说法 | 差在哪 |
|---|---|---|
| 据新闻报道，某省挂牌了一个政府牵头的AI计算中心 | 数字基础设施建设、新型数字基础设施、公共算力供给、普惠算力供给体系 | 全文没有一个关于算力规模、价格、利用率、谁在用的数字 |
| 一个"省份×年份"的0/1变量 | 地区有效算力供给条件的改善 | 理论模型里的Q是连续的"有效算力"，实证里是个开关 |
| 2016—2023年一直挂牌的新三板公司 | 中小企业（97.8%符合工信部划型标准） | 平衡面板只留得下幸存者 |
| IPC号落在国知局AI清单里的专利申请 | AI创新 | 按这个口径，2010年全国就有13万件"AI专利" |
| ln(1+AI专利数)差0.019，10%显著 | "显著增加了企业的AI专利申请数量，平均增加了约2%……具有重要的现实意义" | 至少七成的观测是0，不能读成2%（理由见第五部分） |
| 事前AI专利多的行业，在建中心的省份涨得多一点 | 算力渠道的支持性证据 | 任何针对AI产业的省级政策包都会产生同样的图案 |
| 非AI专利：点估计0.030，比AI专利还大，只是不显著 | 安慰剂检验：对非AI专利没有显著影响，缓解了整体创新环境改善的担忧 | 不显著≠没效应 |
| 研发人员、AI招聘也多了，多数只有一颗星 | 企业资源配置反应与要素互补理论预期一致 | 量级互相对不上 |
| 在柯布-道格拉斯函数上求交叉偏导 | 构建简化模型，刻画算力与研发投入、人力资本的互补关系 | 结论就是假设 |
| 专利挂的IPC大组更分散一点 | AI创新质量提升 | "质量"=分类号分散度 |
| 在AI专利上署过名的人，更多出现在非AI专利上 | AI知识向非AI技术领域扩散 | AI专利多了，"AI发明人"名单自然变长，机械相关 |
| 两个TFP估计各一颗星 | 提升了企业全要素生产率 | — |
| 国企组、大企业组不显著 | 对民营企业和小规模企业的促进作用更强 | 没报组间差异检验，结果在附录 |
| 不知道哪家企业真用过这些中心 | 脚注："本文识别的是地区公共算力供给条件改善对本地中小企业AI创新的平均影响" | 标题和摘要里却一直是"公共算力供给促进了……" |
| 两页施政建议 | "为更好发挥有为政府和有效市场作用、提高公共算力资源配置效率提供政策参考" | 没有一条被本文检验过 |

### 反向演示：一句话是怎么扩成24页的

```
一句话本质："建了中心的省，小公司AI专利多了一点点"
→ 标题：三个大词用顿号和"与"串起来——"数字基础设施建设、公共算力供给与AI创新"
→ 副标题：补一个"——来自XX的证据"
→ 开头：两次全会 + 一个"人工智能+" + 一个部委行动方案
→ 痛点：写"中小企业算力可得性不足"，不用给数据
→ 处理：把"省里挂牌"改名"公共算力供给"
→ 理论：一个名牌理论（实物期权）+ 一个必然推出正号的函数
→ 贡献：三支文献，各说一遍"首次/拓展了"
→ 实证：表1 + 一张事件研究图 + 十几项"详见附录"
→ 机制：找一个"本来就更依赖X的群体"做三重差分
→ 锦上添花：质量、扩散、TFP各一张表
→ 尾巴：两页政策建议
```

## 四、全文结构大白话

### 骨架

```
中央说要搞AI、要"人工智能+"
→ 小公司买不起算力（断言，没有数据）
→ 政府在一些地方建了公共算力中心，还发算力券
→ 那就比一比：建了中心的省 vs 没建的省，新三板小公司的AI专利
→ 多了一点点（0.019，一颗星）
→ 画张图：建之前没差别（其实事前三期都在−0.02）
→ 跑十来种稳健性，全放网络附录
→ 本来就搞AI的行业涨得更多 → "是算力在起作用"
→ 研发、研发人员、AI招聘也多了 → "要素互补"
→ 专利质量、知识扩散、TFP也涨了 → "不光有量，还有质"
→ 给政府四条建议（约2页）
```

## 五、逐段拆：每一段卖的什么药

格式：**说了啥**（大白话）→ **卖啥药**（这一段在论文里的功能）→ **看穿**（实际证明了什么、漏了什么）。

### 摘要（逐句）

| 原句 | 大白话 | 药 |
|---|---|---|
| 智能算力是推动AI创新的关键要素，但较高的算力获取成本可能制约中小企业开展AI创新。 | 小公司可能买不起算力。 | 预设痛点。全文没有一个算力价格或企业用算力的数字 |
| 本文利用自2019年以来各地先后建设公共人工智能计算中心这一准自然实验，采用多期双重差分模型…… | 有的省建了，有的省没建，比一比。 | "准自然实验"：建不建、何时建，是地方政府自己选的 |
| 研究发现，公共智算中心建设显著增加了企业的AI专利申请数量， | ln(1+AI专利)多了0.019，10%水平。 | 只说"显著"，不说几颗星 |
| 且这一影响在AI企业和潜在算力需求较强的企业中更为明显。 | 经营范围里写了AI的公司、AI专利多的行业，涨得多一点。 | 给"算力渠道"铺路 |
| 公共智算中心建设还促进了企业研发投入和AI技能人才配置。 | 研发支出（一颗星）、研发人员、AI招聘（一颗星）也多了。 | 回收理论部分的H2a、H2b |
| 异质性分析表明……对民营企业和小规模企业AI创新的促进作用更强。 | 国企组、大企业组不显著。 | 贴合"普惠"叙事 |
| 进一步研究发现……提高了AI创新质量，促进了AI知识向其他技术领域扩散，并提升了企业全要素生产率。 | IPC大组更分散了；AI发明人的名字在非AI专利里出现得更多了；TFP一颗星。 | "量、质、溢出、效率"四连胜 |
| 本文从公共算力供给的视角……也为优化公共算力资源配置、完善普惠算力供给体系提供了政策启示。 | 我们给政府写了建议。 | 决策咨询价值 |

### 引言

**第1段：中央文件开道**（p74）
- **说了啥**：三中全会说要完善AI等战略性产业政策；四中全会说要智能化；AI是"新一轮科技革命的战略性技术"（引Aghion、Acemoglu撑场）；在"人工智能+"背景下，如何让中小企业用上AI要素，"已成为……重要现实问题"。
- **卖啥药**：先把研究问题绑到最高层级的政策议程上，编辑和审稿人读完默认"这题重要"。这在国内顶刊几乎是规范动作。
- **看穿**：这一段没有一句是本文要检验的命题。它顶替掉的是一篇论文本该有的东西：学术上我们不知道什么、为什么值得知道。

**第2段：制造痛点**（p75）
- **说了啥**：算力、算法、数据是AI三要素；自建算力贵，租商业算力也贵；所以"算力资源可得性不足已经成为阻碍中小企业进行AI创新的重要因素"。
- **卖啥药**：把后文的"处理"预先定义成"缓解痛点"。读者只要接受"小公司缺算力是瓶颈"，后面任何正系数都会被自动读成"瓶颈缓解了"。
- **看穿**：整段没有一个数字：算力多少钱、多少中小企业在用算力、多少企业因为算力放弃了研发，都没有。痛点是断言出来的。

**第3段：把政府工程升格成"研究场景"**（p75）
- **说了啥**：十四五、十五五都在推算力；公共智算中心是地方政府改善AI要素供给的"重要制度实践"，杭州、成都的文件都说要降低中小企业门槛；于是这"提供了具有中国特色的研究场景"。
- **卖啥药**：两级跳：地方基建项目 → "制度实践" → "研究场景"。"具有中国特色"几个字，把"数据来自中国"变成了一项贡献。
- **看穿**：文件写着"降低门槛"，不等于门槛真降了。政策目标被当成了政策事实。

**第4段：在实证之前先把机制写成事实**（p75）
- **说了啥**：2019年起多地建中心，提供普惠算力，还发算力券；因此公共智算中心"有助于提高中小企业的算力可得性……并通过增强算力与研发投入、人力资本之间的互补作用，激励企业增加相关创新要素配置"。
- **卖啥药**：还没跑任何回归，结论链条（可得性↑ → 要素投入↑ → AI创新↑）已经写成陈述句。后面的"机制检验"只要找到方向一致的系数，就算"呼应"了。
- **看穿**：注意"算力券"。它是财政补贴。处理变量从一开始就把"建机房"和"发钱"捆在一起，后文却只讲"算力供给"。

**第5段：交代做法和发现**（p75—76）
- **说了啥**：新三板2016—2023年，国知局专利数据，"构建独特的企业AI专利数据库"，多期DID；发现三条（同摘要）。
- **卖啥药**："构建独特的数据库"，指的是用一张IPC清单把专利筛出来。
- **看穿**：见下文"研究背景（一）"对"AI专利"口径的分析。

**第6—8段：三条"边际贡献"**（p76—77）
- **说了啥**：①基础设施与创新：以前研究高铁、公路、宽带、物联网，"本文首次聚焦公共智算中心"；②AI创新的决定因素：以前研究数据，本文研究算力；③政府引导创新：以前研究补贴、税收、产业政策、引导基金、人才……本文研究"通过基础设施改善关键要素供给"。
- **卖啥药**：固定句式"XX文献研究了A、B、C，但鲜有文献研究D，本文首次……拓展了XX研究"。贡献就是填一个空格，而且三条贡献其实是同一件事，换了三个文献框各说一遍。
- **看穿**：第③条特意强调"不同于直接向企业提供资金支持"，可处理变量里恰恰捆着算力券，也就是直接给钱。

**第9段：政策意义**（p77）
- **说了啥**：算力重要，中小企业有约束；工信部、财政部等四部门2024年12月的《中小企业数字化赋能专项行动方案（2025—2027年）》强调中小企业AI创新，"凸显了本文研究的现实意义"；最后落到"为更好发挥有为政府和有效市场作用……提供了政策参考"。
- **卖啥药**：第二次政策背书，把读者从学界延伸到决策层。决策咨询价值在国内评价体系里是加分项。

**第10段：结构安排**：纯格式，略。

### 二、研究背景（科普区）

**（一）AI创新及其趋势**（p77—78）
- **说了啥**：用WIPO的定义说什么是AI创新；提2017年《新一代人工智能发展规划》；图1：中国AI专利申请从2010年13万件涨到2022年80万件，年均增速超过15%，以发明专利为主；数量世界第一，但顶尖模型不如美国，需要提质。
- **卖啥药**：一是继续铺垫"AI很重要"；二是用图1让"AI专利"看起来是个像样的指标。
- **看穿**：
  - 这张图恰恰暴露了口径有多宽。2010年深度学习还没火（AlexNet是2012年），按本文口径中国就有13万件"AI专利"申请；而国知局统计的2010年发明加实用新型申请一共约80万件（发明约39.1万、实用新型约40.9万），等于六分之一都算"AI"。后面所有"AI创新""AI发明人""AI知识扩散"都建在这个口径上。
  - 图1里2023年比2022年还低。发明专利申请后最长18个月才公开，本文样本恰好截止2023年，正文没有讨论公开滞后造成的截断（同一个压缩包里肖柏高那篇就专门做了调整）。

**（二）算力类别**（p78—79）
- **说了啥**：算力定义、FLOPS；通用算力、智能算力、超级算力；CPU、GPU、ASIC、FPGA、NPU；中国2022年算力总规模302 EFLOPS。
- **卖啥药**：营造"跨学科专业感"。经济学期刊里讲芯片分类，显得作者懂技术，也让"算力"这个处理显得很具体。
- **看穿**：这一节的所有概念，后面实证一个都没用上。回归里没有任何算力数量：多少PFLOPS、什么芯片、什么价钱，都没有。

**（三）智算中心类别**（p79）
- **说了啥**：智算中心分公共（政府主导）和商业（头部企业主导）；举例武汉人工智能计算中心（2021年5月投用，武汉市委市政府牵头，东湖高新区承建，湖北省科投集团和华为共同交付）；商业的有中国电信、商汤、阿里云和小鹏合建的"扶摇"。
- **卖啥药**：给"公共 vs 商业"的对照做铺垫。后文控制商业智算中心而它不显著，就可以说"起作用的是公共算力的普惠性"。
- **看穿**：商业智算中心多是给自己和供应链建的，本来就不对外普惠。拿它当对照，"公共有效、商业无效"几乎是预设好的。

**（四）使用成本与补贴**（p79—80）
- **说了啥**：公共智算中心有电价优惠、财政资金支持，所以更便宜；地方发算力券，武汉最高20万元、兑付30%；作者整理各省政策，算力券平均补贴约30%；结论：公共智算中心有"普惠特征"。
- **卖啥药**：给"处理=算力变便宜"提供事实依据。
- **看穿**：
  - 没有给出任何一家公共中心和商业中心的实际报价对比，"更便宜"是断言；手工整理的是文件上写的补贴比例，不是企业实际拿到的补贴。
  - 更要紧的是，算力券是财政转移支付，而且有的地区也补贴商业算力。所以系数即使为正，也分不清是"算力供给改善了"还是"政府给钱了"。
  - **对财政学来说，这恰恰是最该问的问题：同样一笔钱，建机房和直接发券，哪个效果大？本文没问。**

### 三、理论分析与研究假说（装修区）

**第1段：AI创新是多要素联合投入**（p80）
- **说了啥**：AI创新需要算力、算法、数据、人力资本（引LeCun、Azoulay、Babina，以及王勇等2026）；AI创新更算力密集，所以算力供给影响创新的可行性和效率。
- **卖啥药**：把常识写成"理论分析"的起点。
- **看穿**：被引来证明"AI创新的决定因素是算法、算力和数据"的"王勇等（2026）"，就是上一批材料里那篇3家企业的算力共享模型。

**第2段：实物期权**（p80—81）
- **说了啥**：企业采用新技术要做专用性投入，项目停了收不回来；算力供给不确定时，等待有期权价值；公共智算中心提高了算力供给的"稳定性和可预期性"，等待价值下降，企业就更愿意投入（引McDonald & Siegel 1986；Alessandria et al. 2025）。
- **卖啥药**：借一个名牌理论给文章加理论厚度。
- **看穿**：
  1. "提高了稳定性和可预期性"是断言。
  2. Alessandria等（2025，*JPE*）研究的是60年中美贸易政策动态，被拿来给"算力供给稳定降低等待价值"背书。
  3. 下一步的模型里完全没有不确定性，期权理论讲完就扔了。

**第3段：互补性**（p81）
- **说了啥**：算力不能单独产生AI成果，要与研发投入、专业人才结合；中心建成后研发和人力的边际产出提高，企业就会多投（引Brynjolfsson & Milgrom 2013等）。
- **卖啥药**：为H2a、H2b准备文字依据。

**第4段 + 简化模型**（p81—82）
- **说了啥**：设AI创新产出 Y = A·Q^α·R^β·H^γ（Q是地区有效算力，R是研发，H是人力资本）；求交叉偏导大于0，叫作"互补"；利润最大化后得到 ∂lnY\*/∂lnQ = ∂lnR\*/∂lnQ = ∂lnH\*/∂lnQ = α/(1−β−γ) > 0。
- **卖啥药**：一页纸公式把"理论分析"从文字升级成"模型"，满足"有理论推导"的审稿要求，还能给每个假说配一个"推导"。
- **看穿**：
  1. **结论就是假设。** 只要把Q放进柯布-道格拉斯函数并设α>0，交叉偏导必然为正、弹性必然为正。这个模型没有能力给出"算力中心没用"的结果。
  2. 实证里的Q是一个0/1（省里有没有中心），不是"有效算力供给"。
  3. 模型预言三者对Q的弹性完全相同。实证里研发投入约+2%、研发人员约+9%、AI专利"约+2%"，量级对不上，文中不讨论。

**假说**（p82）：H1"公共智算中心建设通过改善地区有效算力供给，促进中小企业AI创新"；H2a研发投入增加；H2b人力资本增加。
- **看穿**：H1本身就写进了机制（"通过改善地区有效算力供给"），但全文没有任何算力供给的度量。

### 四、数据与研究设计

**样本：新三板代表中小企业**（p82）
- **说了啥**：三条理由：97.8%符合工信部中小企业划型标准；和上市公司差距大；信息披露透明。
- **卖啥药**：用一个精确到小数点的数字（97.8%）赋予代表性。
- **看穿**：样本是5023家 × 8年 = 40184个观测的**平衡面板**，只有2016—2023年一直挂牌的公司才进得来。新三板2018年后经历了大规模摘牌，留下来的是幸存者。另外，新三板公司多数根本不申请AI专利（见下文"至少七成是0"），"中小企业AI创新"的样本基础很薄。

**数据来源**（p82—83）
- **说了啥**：AI专利按国知局《关键数字技术专利分类体系（2023）》的IPC号筛选；智算中心的上线时间从新闻报道和公开网站手工检索；按企业所在地匹配；AI企业从天眼查经营范围关键词识别。
- **看穿**：
  - **哪些省、哪一年算"处理组"，是全文最关键的一张表，放在网络附录里。** 描述性统计、全部稳健性检验、异质性分析、替代解释的结果也都在附录。
  - "AI企业"有10448个观测，约占样本26%：四分之一的新三板公司，经营范围里写了AI相关词。

**模型**（p83）
- **说了啥**：因变量 ln(1+AI专利数)；核心变量是"企业所在省份当年是否已建公共智算中心"；控制商业智算中心、企业年龄、规模、负债率、ROA；企业固定效应加年份×行业固定效应（引Albertus et al. 2025，一篇研究美国税改的论文，为"用了年份×行业固定效应"背书）；标准误聚类到省份。
- **脚注原文**："本文的解释变量旨在刻画企业所在地区公共算力供给条件的变化，而非企业实际使用某一公共智算中心的行为。"
- **卖啥药**：这个脚注是全文最诚实的一句话，也是最关键的免责声明：作者知道自己没有使用数据。可正文和摘要里一直写"公共算力供给促进了……"。
- **看穿**：
  1. 处理在省份层面：武汉建了中心，恩施、十堰的公司也算"被处理"。
  2. 全国只有三十来个省份，标准误聚类在省份，真正独立的信息其实就是几十个省份的时间序列。
  3. 因变量是ln(1+x)，大量为0。

### 五、实证结果

**（一）基准回归**（p83—84，表1）
- **说了啥**：不加任何控制，系数0.076；加企业、年份×行业固定效应，降到0.022（一颗星）；再加控制变量，0.019（一颗星）；商业智算中心不显著。经济意义："AI专利申请数量平均增加了约2%（e^0.019−1）。考虑到多数企业尚未深度参与AI创新活动，这一提升具有重要的现实意义。"AI企业子样本0.055（三颗星），"体现了公共算力供给对AI创新核心主体的强化促进作用"。
- **卖啥药**：全文唯一的核心发现，只占一页多。话术三件套：①只说"显著"，不说几颗星；②把对数差换算成"约2%"，听起来很具体；③系数小，就换一个参照系（"考虑到多数企业尚未深度参与"）。
- **看穿**：
  1. **0.076 → 0.022**：建中心的省份本来就是AI专利多的省份，选择效应巨大。剩下的0.02，全靠平行趋势假设撑着。
  2. **0.019，标准误0.011**：t≈1.7，只在10%水平显著，而且聚类只有三十来个省份。
  3. **"约2%"不成立**：表1第(1)列常数项显示，对照组的 ln(1+AI专利数) 均值只有0.19。只要有1件专利，ln(1+1)=0.69，所以**至少七成的公司-年份一件AI专利都没有**。在这种变量上，系数不能读成百分比变化。作者在稳健性里引用的Chen & Roth（2024，*QJE*，"Logs with Zeros?"）讲的正是这件事；他们用泊松回归做了稳健性，但结果放在附录。
  4. "商业智算中心不显著"暗示"公共的才有用"，但前面说过，商业中心本就不对外普惠。
  5. AI企业用经营范围关键词定义，四分之一的样本都算"AI企业"。

**（二）平行趋势**（p85，图3）
- **说了啥**：事件研究图，以建中心前一年为基期，"公共智算中心建立前各期系数均不显著……本文的分析结果满足平行趋势假设"。
- **卖啥药**：DID文章的通行证，一张图加一句"均不显著"。
- **看穿**：**看图，别看字。**
  - 建中心前第4、3、2年的系数目测约为−0.020、−0.015、−0.019，三个全在0以下；基期（前1年）被设成0。这意味着从前2年到前1年，处理组相对对照组已经涨了约0.02，和整篇文章的"政策效应"0.019是同一个量级。
  - 每个点的置信区间都包含0（前3年那个的上沿几乎贴着0），所以"单个不显著"；但三个点同号、同大小，本身就是趋势信号。文中没有报告联合检验。
  - 建成当年（t=0）系数就约0.025，比平均效应还大。中心刚挂牌的当年，小公司的AI专利申请就涨上来了，这与"租算力 → 做研发 → 申请专利"的时间链条对不太上，更像是同期别的东西在起作用。

**（三）稳健性检验**（p85—86）
- **说了啥**：重新界定中小企业；安慰剂（建立时间提前3期、4期；随机处理组）；堆叠DID；泊松回归；剔除从未建中心的省份、剔除商业中心先建的省份、剔除商业中心建设企业的供应链企业；以6月30日为界重新定处理年份；控制处理组的线性和二次趋势；PSM；合成DID。"一系列检验结果均佐证了本文研究结论的稳健性。"
- **卖啥药**：清单式防御，堵审稿人的嘴。十几项检验，正文里一个数字都没有，全部"详见附录"。
- **看穿**：这些都是规范动作，方向没错（堆叠DID、合成DID、泊松都是对的工具）。但稳健性检验回答的是"换个估计方法，结果还在不在"，回答不了"处理变量到底测的是什么"。

**（四）排除替代性解释**（p86）
- **说了啥**：控制人工智能创新发展试验区、省级公共数据开放平台、企业政府补贴、"东数西算"节点后，仍显著（附录）。
- **卖啥药**："你想到的我们都想到了。"
- **看穿**：控制的是几个"有没有"的哑变量。地方的AI产业政策是一揽子的（AI产业园、招商补贴、专利资助、高新技术企业认定……），建中心往往只是其中一项，控不完。本文参考文献里有黎文靖、郑曼妮（2016）《实质性创新还是策略性创新？》，却没有检验新增的AI专利是不是冲着地方专利资助、高企认定去的"策略性专利"。

**（五）异质性**（p86—87）
- **说了啥**：民营企业显著、国企不显著；小企业显著、大企业不显著；"与公共算力供给改善对资源获取能力相对有限的企业具有更大边际影响的理论预期一致"。
- **卖啥药**：把"一组显著、一组不显著"讲成故事，正好贴合"普惠算力""支持中小企业"的政策叙事。
- **看穿**：
  1. "一组显著一组不显著"不等于两组有差异，正文没报组间差异检验，结果在附录。
  2. 新三板里国企本来就少，不显著很可能只是样本小。
  3. 这种预期可以事后写：如果结果反过来，同样可以写"国企承担国家AI战略任务，更积极使用公共算力"。

### 六、算力渠道与企业资源配置（机制区）

**（一）"算力渠道的支持性证据"：三重差分**（p87—89，表2）
- **说了啥**：用2018年各行业AI专利占比衡量"潜在算力需求强度"，与公共智算中心交乘，再加城市×年份固定效应，交乘项0.065—0.069，显著。按需求高低分组：高需求组0.037显著、低需求组−0.005不显著。以非AI专利（剔除AI发明人参与的）为因变量：0.030，不显著。结论："为……算力渠道提供了支持性证据"，并"缓解了……地区整体创新环境普遍改善……的担忧"。
- **卖啥药**：全文从"相关"跳到"机制"的关键一步。措辞很讲究：正文用"支持性证据""与理论预期一致"，到了摘要和结论就成了"通过改善地区有效算力供给"。
- **看穿**：
  1. 公道话：三重差分加城市×年份固定效应，是全文设计上最像样的一步。
  2. 但它识别的是"事前AI密集的行业，在建了中心的省份，比非AI行业多涨了一点"。任何针对AI产业的省级政策包（AI产业园招商、AI企业补贴、专利资助）都会产生一模一样的图案，并不专属于"算力"。
  3. 仍然没有任何一家企业的算力使用数据。
  4. **技术疑点**：按正文定义，公共、商业智算中心都是"省份×年份"层面的0/1，加了城市×年份固定效应后应当被完全吸收、估不出来。表2 Panel A却照样报告了它们的系数，公共智算中心的标准误从基准的0.011暴涨到约0.15，说明处理变量和固定效应之间近乎共线。文中没交代原因。
  5. **"安慰剂"反噬**：Panel B第(3)列非AI专利的系数是**0.030，比AI专利的基准系数0.019还大**，t值约1.5，和基准的1.7差不多，结论却是"没有显著影响"。按点估计读，数据其实在说：建了中心的省份，非AI创新也一样在涨，这恰恰是作者想排除的"整体创新环境改善"。

**（二）研发投入**（p89）
- **说了啥**：ln(研发投入)系数0.020（一颗星），"平均增加约2%"，"与算力和研发投入之间存在要素互补关系的理论预期相一致"。

**（三）人力资本**（p89—90，表3）
- **说了啥**：研发人员0.090（两颗星，"约9%"）；本科及以上员工0.015（一颗星）；AI技能岗位招聘0.033（一颗星）；非AI岗位招聘0.025（不显著）→ "招聘需求的增加并未普遍扩展至非AI岗位"。
- **卖啥药**：把理论部分的H2a、H2b逐个"验证"：模型说会增加，数据也增加了，形成闭环。
- **看穿**：
  1. **量级对不上**：研发人员多了9%，研发投入只多了2%。人多了四倍多的比例，钱几乎没动，而模型预言二者弹性相同。
  2. 非AI招聘0.025和AI招聘0.033，点估计差不多，只是标准误一大一小。又是"不显著=没效应"。
  3. 这些都是"省里建了中心之后，公司的X变了"，没有一条连到"用了算力"。

### 七、进一步分析（锦上添花三连）

**（一）质量**（p91）
- **说了啥**：AI专利"知识宽度" = 1 − Σ（各IPC大组占比）²，显著为正 → "显著提升了AI专利的质量"。
- **看穿**：一件专利挂的IPC大组越分散，就算"质量"越高。IPC号多由审查员和代理人给出，拿它当质量是国内文献的惯例（引张杰、郑文平2018），但离"质量"很远。

**（二）扩散**（p91）
- **说了啥**：先引一段习近平关于AI"头雁效应"的讲话；测度是：企业AI专利的发明人，也出现在非AI专利上的比例；显著为正 → "推动AI知识向其他非AI技术领域扩散"。
- **卖啥药**：领导人讲话充当这一小节的"理论依据"。
- **看穿**：这个指标带机械性。只要处理让企业多申请了AI专利，"AI发明人"名单就会变长，这些人同时出现在非AI专利上的比例自然上升，不需要任何"知识扩散"。

**（三）全要素生产率**（p91—92）
- **说了啥**：OP法0.016、GNR法0.036，都只有一颗星 → "提升了企业的全要素生产率水平"。
- **看穿**：新三板公司的"中间投入"是用营业成本+三费−折旧−职工现金拼出来的，TFP估计误差很大；两个一颗星的结果被写成"提升了"。

**这一节整体卖的药**："不仅有量，还有质、有溢出、有效率"。这是国内实证文章"进一步分析"的标准三件套，几乎每篇都有，用来把一个发现撑成一个体系。

### 八、结论与政策建议（尾巴区）

- **说了啥**：重复三条发现，然后四条建议，约2页：
  1. 有效市场与有为政府结合，因地制宜布局：评估需求，审慎新建，"避免将公共智算中心建设简单视为地方产业竞争和招商引资的手段"，解决"设备闲置"；
  2. 面向中小企业的普惠和精准支持：按真实需求准入、公开透明、"动态退出机制"；
  3. 从单一算力平台转向综合性AI创新服务平台：技术服务、人才培养、数据协同、场景开放；
  4. 以实际使用和创新产出为导向的绩效评价：利用率、覆盖面、绿色运行、信息公开。
- **卖啥药**：决策咨询价值；回扣"有为政府、有效市场"。
- **看穿**：
  1. **没有一条建议被本文检验过**：本文没有利用率、价格、闲置、能耗、准入、退出的任何数据。
  2. 建议里反复出现"设备闲置""招商引资""长期占用但利用率较低"。作者其实知道公共智算中心可能大量闲置、可能是招商工具，而这正好动摇了"建中心 = 改善算力供给"这个前提。可正文从没测过利用率。
  3. 政策建议（约2页）比核心结果（约1.4页）还长。

## 七、说句公道话：它做对了什么，为什么能上《经济研究》

- **这不是烂文章。** 设计规范，检验齐全，作者懂方法：堆叠DID、合成DID、Chen & Roth的泊松、带城市×年份固定效应的三重差分，方向都对。政策建议里甚至主动提到"闲置""招商引资"的风险。
- **问题不在"造假"，在三个落差**：
  1. 测到的（省里有没有挂牌中心） vs 声称的（公共算力供给）；
  2. 估出来的（一颗星的0.019） vs 讲出来的（"显著增加""具有重要现实意义"）；
  3. 检验过的（专利、研发、招聘） vs 建议的（利用率、退出机制、绿色运行）。
- **为什么能发**：选题踩在政策热点上，天然"首次"；规范动作一个不缺；机制和进一步分析把一个薄结果撑成了体系；政策建议满足决策咨询导向。每道工序都有模板，所以能大规模复制。缺的只有一样东西：一个足够硬的核心发现。
- **从财政学看**：这本质是一篇公共投资项目评估（JEL H54）。真正该问的财政问题一个都没回答：建一个中心花了多少钱、利用率多少、算力券和建机房哪个更划算、有没有挤出商业算力。
