# 最新的 C：四中全会、十五五纲要里的热词，已发文章怎么用的

> 目的：只看"新到师兄师姐挑不出'太老'"的 C。找出已发表文章里用这些 C 的，看它们配了什么 A、用了什么指标、出了什么问题，以及有没有更好的指标和冲击。
> 样本：财税 45 篇全文中，引言引了二十届四中全会 /"十五五"规划建议（2025.10）、2025 年中央经济工作会议（2025.12）或"十五五"规划纲要（2026.3）的 17 篇（逐篇依据见 `02_批量检验/财税45篇_逐篇编码.md`）；另从 258 篇目录按关键词补了 2 篇（WE-015、FISC-023），这 2 篇只看过摘要。
> 标"需核实"的政策时间，动笔前对照原文件。

## 一、先筛：哪些 C 是真新的

判断标准：**这个词是不是 2025 年以后才写进顶层文件、成为提法**。只是"新文件里又重复了一遍"的老词，不算。

| 档次 | C 词 | 关键出处 | 已发文章 |
|---|---|---|---|
| **真新** | 投资于人 | 2025 政府工作报告首次写入；四中"十五五"建议"投资于物和投资于人紧密结合"；2025 中央经济工作会议"必须坚持" | FISC-017（主线）、FISC-011、FISC-012、ERJ-034（挂引言） |
| **真新** | 财政科学管理（连带零基预算） | 四中"十五五"建议"加强财政科学管理" | ERJ-034 |
| **真新** | 健全预期管理机制 | 2025 中央经济工作会议"健全预期管理机制，提振社会信心" | FISC-003；WE-015、FISC-023（摘要） |
| **真新** | 综合整治"内卷式"竞争 | 2024.7 政治局会议首提；2024、2025 中央经济工作会议"综合整治"；四中建议 | FISC-024（挂引言），FISC-025（延伸） |
| **较新** | 生育支持、生育友好型社会 | 十五五纲要"优化生育支持政策和激励措施……发挥育儿补贴和……个税专项附加扣除政策作用" | TAX-006 |
| **较新** | 房地产高质量发展、房地产发展新模式 | 四中"十五五"建议 | CMJJ-002 |
| **较新** | 增强社会保险体系可持续性 | 十五五纲要 | ERJ-041 |
| 旧词新引 | 逆周期和跨周期调节、宏观经济治理效能 | 2020 年起就有，2025 中央经济工作会议和纲要重复 | ERJ-040、MWM-015、CMJJ-041 |
| 旧词新引 | 健全有利于高质量发展、社会公平、市场统一的税收制度 | 三中《决定》原句，纲要沿用 | ERJ-017、ERJ-020、ERJ-023 |
| 旧词新引 | 三医协同（"三医联动"2016 年就有） | 四中建议 | ERJ-007 |
| 旧词新引 | 现代化产业体系、税收治理现代化 | 二十大及更早 | CMJJ-041、FISC-025 |

**旧词新引的这一档不建议当 C**：师兄说"老"是对的，这些文章只是在引言换了个新出处。

## 二、七个新 C 逐个评析

### 1. 投资于人

| | 已发文章的做法 | 更好的做法 |
|---|---|---|
| **A** | FISC-017：财政缺口（连续变量，不是冲击）+ 2016 年义务教育公用经费央地分档 + 2019 年医疗卫生央地分档；FISC-011：2016 年义务教育经费保障改革中县级分担比例（强度 DID） | **学生营养改善计划**（2011 年起国家试点县 vs 非试点县，天然分组）；**免除学前一年保育教育费**（2025 年秋季全国实施，要找地方先行的差异，需核实）；**地方育儿补贴**（先行城市分批） |
| **C 指标** | 教育支出占比、公立医院数、医师数、图书馆藏书（FISC-017）；家长自报孩子成绩 1—4 档（FISC-011） | 投入层：人均教育、社保就业、卫生健康支出（决算功能分类）；**结果层**：儿童身高体重（CFPS、CHNS）、学生标准化成绩（CEPS）、入园率 |
| **文章问题** | FISC-017 医疗 DID 的对照组只有北京、上海，没有事前检验，医院数效应约 97%，量级难以置信；理论模型里"地方投资于人为零"是任期假设直接决定的。FISC-011 稳健性全部备索，事前只有两期，效应只在 2020、2022 年（疫情期）显著 | |

**一句话**："投资于人"的人字没被测到。已有文章测的是"钱花没花、楼盖没盖"，应该测孩子长高没有、成绩涨没有。

### 2. 财政科学管理、零基预算

| | 已发文章的做法 | 更好的做法 |
|---|---|---|
| **A** | ERJ-034：预算管理一体化系统分批上线（2020—2022） | **零基预算改革分省推开**（手工整理各省时间）；一体化上线也可以用，但样本要延到 2023 年以后，躲开疫情 |
| **C 指标** | 超效率 SBM-DEA 的效率变化指数，产出里混着每万人移动电话数、人均燃气用量 | **把它自己的机制变量升格为 C**：12 月支出占全年比重、政府采购合同 12 月占比、预决算偏离度、审计违规金额。这些在 ERJ-034 里都已显著，而且直接对应"科学管理" |
| **文章问题** | 效率指数是相邻期变化，却被当成效率水平来解读；民生支出 +6.36% 与总支出 +0.27%（不显著）对不上；识别检验全在附录；样本止于 2022 年，与疫情重叠 | |

**一句话**：这篇最好的 C 被它自己放进了机制部分。"年底突击花钱"比 DEA 黑箱好讲十倍。

### 3. 健全预期管理机制

| | 已发文章的做法 | 更好的做法 |
|---|---|---|
| **A** | FISC-003：财政部网站"财经视点"栏目转载新闻的日度语调；WE-015：国新办发布会；FISC-023：2019 年增值税法征求意见稿（摘要） | **高频事件研究**：发布会、政策公告的精确时点（分钟级），取公告前后 30 分钟窗口；再用公告内容与事前市场预期之差做"意外成分" |
| **C 指标** | 个股收盘价水平和成交量（FISC-003），"异质性预期"没有直接测量 | **直接测预期**：分析师一致预期及其分歧（Wind）、央行城镇储户问卷和企业家问卷、国债期货和股指期货、期权隐含波动率、上市公司业绩说明会的前瞻语调。WE-015 用"市场专业人士预期"，方向是对的 |
| **文章问题** | FISC-003 的语调是全国日度变量，却配 746 万个股观测、不按交易日聚类，标准误严重低估；同一变量在 12 个指数层面全部不显著；用"收盘价高低"代理"权重股"，与指数按市值加权的规则不符 | |

**一句话**：预期管理的 C 就是"预期"本身，有现成的问卷和期货数据，别拿股价水平去代替。

### 4. 综合整治"内卷式"竞争

| | 已发文章的做法 | 更好的做法 |
|---|---|---|
| **A** | FISC-024：2014 年 43 号文 + 新《预算法》 × 城市对的财政纵向失衡差（强度 DID） | 《公平竞争审查条例》（2024 年 8 月施行）；规范招商引资、清理违规返还的文件（需核实时间）；2014 年国发 62 号清理税收优惠、2015 年国发 25 号又暂停（一收一放，旧冲击但干净） |
| **C 指标** | 跨市新设子公司的注册出资额（FISC-024），测的是资本流动，**没测到"内卷"** | **上市公司"政府补助"明细**（地方补贴大战）；光伏、锂电、新能源车的价格、毛利率、产能利用率；**政府采购本地企业中标比例**（地方保护）；企业跨市迁址（工商登记） |
| **文章问题** | FISC-024 把"流向欠发达地区的资本减少"定性为"市场之手"，没有效率检验；处理在城市层面，聚类在城市对；只保留正流量；机制用的营商环境指数由财政规模、存贷款、床位数拼成 | |

**一句话**：我们看过的文章里还没有一篇真正测"内卷"，这是最大的空白。

### 5. 生育支持

| | 已发文章的做法 | 更好的做法 |
|---|---|---|
| **A** | TAX-006：2019 年个税改革整体（基本减除费用 + 六项专项附加扣除） | **2022 年新设的 3 岁以下婴幼儿照护专项附加扣除**、**2023 年起专项附加扣除提标**（婴幼儿照护、子女教育由每月 1000 元提到 2000 元）：按家庭有无适龄孩子 × 边际税率，天然有强度差；**地方育儿补贴先行**（攀枝花约 2021 年起，各地金额不同，需核实） |
| **C 指标** | CFPS"理想子女数"（态度，不是行为） | **实际出生**：CFPS 新生儿、县级出生人口、二孩三孩占比；母婴消费 |
| **文章问题** | 用政策后（2020 年）收入划分处理组，实质是高收入组；没有平行趋势检验，还说"仅有政策前一期"，与实际用了 2014、2018 两期矛盾；政策后只有 2022 年一期；政策建议给出的扣除额度和负所得税方案都没检验 | |

**一句话**：意愿不等于行为；专项扣除提标和地方补贴都是天然分批的好冲击。

### 6. 房地产高质量发展、发展新模式

| | 已发文章的做法 | 更好的做法 |
|---|---|---|
| **A** | CMJJ-002：2008—2011 年房地产评税技术试点 | **各城市取消或放松限购的时间**（2022—2024 年陆续，天然分批）；**城市房地产融资协调机制"白名单"**（2024 年 1 月起分批）；收购存量商品房用作保障房 |
| **C 指标** | 非房地产上市公司"投资性房地产 + 在建工程"的 Richardson 残差 | 住宅价格、网签成交量、房企违约和交付延期、土地出让收入、保障房供给 |
| **文章问题** | "在建工程"多是厂房设备建设，不是炒房；政策针对二手房交易计税价格，与实测对不上；加入限购等同期政策交互后主效应全部不显著；处理在城市层面，聚类在企业 | |

**一句话**：A 太老（2008 年），C 与"房地产"错位；新 A 现成就有好几个。

### 7. 增强社会保险体系可持续性

| | 已发文章的做法 | 更好的做法 |
|---|---|---|
| **A** | ERJ-041：工业机器人渗透度（技术冲击，Bartik 型） | **渐进式延迟退休**（2025 年起，按出生年月和性别分档，可做断点或队列设计）；**个人养老金**（2022 年 36 城先行，2024 年底全国推开，天然分批）；养老保险全国统筹的省际调剂（按上缴和拨付强度） |
| **C 指标** | 企业养老保险缴费额（只有收入端） | **收支两端**：基金当期结余或缺口、财政补助占基金收入比重、实缴和应缴基数之比（缴费遵从）、断缴率、灵活就业参保率 |
| **文章问题** | 企业固定效应下识别只剩 15 个行业 × 5 年的变异，却只用企业层面稳健标准误，显著性很可能被高估；"可持续"只测收入端；从"机器人增加税收"一步跳到"资本收益纳入社保筹资"的制度建议 | |

**一句话**："可持续"是收支平衡概念，只测缴费等于只看了一半。

## 三、汇总

**新 C 一共 7 个，已发文章在这些 C 上的共同毛病有三条：**

1. **C 的指标没测到热词本身。** 投资于人测的是医院数，内卷测的是资本流动，预期测的是股价，可持续只测了缴费。这是最普遍、也最容易被审稿人和师兄挑的。
2. **A 偏老，而新 A 现成就有。** 评税试点（2008）、金税三期（2013）、2019 年个税改革都是旧冲击；2022 年以来已经有一批天然分批的新冲击没人用：专项附加扣除提标、个人养老金、延迟退休、取消限购、白名单、公平竞争审查条例。
3. **技术上的老问题照旧**：聚类低于处理层级（FISC-003、CMJJ-002、ERJ-041、FISC-024），关键检验放附录或备索（ERJ-034、FISC-011），对照组太少（FISC-017 只有京沪），量级不可信（FISC-017 的 97%）。

**最值得做的三个（C 新 + 指标硬 + A 现成）：**

| C | A | 指标 |
|---|---|---|
| 财政科学管理 | 零基预算分省推开 | 12 月突击花钱、采购合同月份分布 |
| "内卷式"竞争 | 公平竞争审查条例、规范招商引资 | 上市公司政府补助明细、本地中标比例、行业价格和毛利率 |
| 生育支持 | 专项附加扣除提标、地方育儿补贴 | 实际出生数、二孩三孩占比 |

"投资于人"也可以做，但一定要测"人"的结果（身高、成绩），而不是投入。
