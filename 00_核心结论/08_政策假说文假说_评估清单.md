# 政策假说文假说：一个故事能不能讲、好不好写

> 对象：四分类里的"讲道理型"及其升级版。这类文章还没有数据，立论方式是"假如有这么一个制度或工具，就能解决国家关心的某个难题"，包括应用构想（把新技术、别的学科嫁接过来）、制度设计、政策与理论阐释。
> 和 `02_冲击回归文假说_演进与检验.md` 对照着读。符号沿用：**C** = 国家关心的结果或难题，**A** = 拿来解决问题的东西，**B** = 中间机制。
> 状态：**假说**，还没有像冲击回归文那样做逐篇全文检验。依据有三类：同刊基准统计（`02_批量检验/五词文献调研/数据/五词合并编码.csv`，去重后 506 篇）、概念类与设计类论文的方法论文献、若干成败案例。刊物要求和案例时间线多数来自检索摘要，标了"检索摘要"的，动笔引用前要对照原文。

## 一、先说结论

> **政策假说文 = 文件已经点名的痛点（C）× 一个"有来头"的外来结构（A：新技术、别的学科、别国或别行业已经在用的制度）× 一次"病因改写"（B：把 C 的病根重新诊断成恰好是 A 能治的那种病）× 一张能落地的条款清单。要想发到中上刊物，还得再加至少一条替代数据的"支撑腿"。**

和冲击回归文比，三个角色都变了：

| | 冲击回归文 | 政策假说文 |
|---|---|---|
| **C** | 热词，常在修改阶段后补进引言 | 痛点，是全文起点也是终点；要有文件原话承认"难、不敢、不会" |
| **A** | 已经发生、分批落地的政策，按"可识别性"挑 | 还没发生的设计，按"有来头、能落地"挑 |
| **B** | 机制变量，跑得出来就写 | 病因诊断，是全文最值钱的部分 |
| **数据** | 必须有，贴合度可以低 | 可以没有；但刊物层级越高，越需要替代证据 |
| **注水手法** | 换指标、换样本，直到显著 | 换名词，直到时髦（区块链 → 大数据 → 联邦学习 → 大模型 → 智能体）；换热词，直到对上 |
| **露馅点** | 处理变量测的不是它声称的东西 | "问题"就是"没用我的技术"；映射只借到名字；对策是"加强、完善、健全" |

冲击回归文有三问：C 是不是国家关心的，A 和 B 有没有数据，能不能讲出 A 促进 C。到了政策假说文，这三问变成第三节的五道门。

## 二、同刊基准：这类文章在哪发、长什么样

### 2.1 刊物分布（我们自己的编码，去重后 506 篇）

数据是五个选题词（投资于人、预期管理、生育、房地产、社保）在十本刊物 2023—2026 年的知网导出，按"文章类型"编码：

| 期刊 | 篇数 | 阐释综述 | 占比 |
|---|---:|---:|---:|
| 税务研究 | 63 | 50 | 79% |
| 财政研究 | 58 | 10 | 17% |
| 财贸经济 | 50 | 5 | 10% |
| 数量经济技术经济研究 | 50 | 3 | 6%（都是方法综述） |
| 中国工业经济 | 22 | 1 | 5%（座谈会纪要） |
| 经济研究 | 53 | 1 | 2% |
| 世界经济 | 51 | 1 | 2%（文献综述） |
| 管理世界 | 49 | 0 | 0 |
| 经济学（季刊） | 52 | 0 | 0 |
| 金融研究 | 58 | 0 | 0 |
| **合计** | **506** | **71** | **14%** |

两个发现：

1. **纯讲道理在顶刊几乎发不了**：管理世界、经济学（季刊）、金融研究都是 0。在《税务研究》，讲道理文是主流；在《财政研究》，占一成多。
2. **《税务研究》以外的 21 篇，作者大多有身份。** 其中 6 篇是综述、书评、座谈纪要；其余 15 篇大多出自知名学者或院所课题组：蔡昉（经济研究）、刘尚希（财贸经济）、吕冰洋、吕炜、杨灿明、丛树海、谢贞发（财政研究），以及财科院等院所的课题组。**在中上刊物，讲道理是资深学者的特权；年轻作者要进这一档，得靠第四节说的"腿"。**

注：样本是按五个热词检索出来的，所以这是"热词题目里的占比"，正好就是我们关心的那个总体。

### 2.2 题目和结构长什么样

71 篇阐释综述的题目里，各类动词出现的篇数：

- 完善、优化、健全、构建、建设、重构：28 篇
- 思考、探析、探讨、刍议：18 篇
- "……视角""……背景下"：15 篇
- 路径、机理、逻辑、机制：11 篇
- 综述、回顾、展望：7 篇
- 经验、借鉴、启示：4 篇

正文结构大致四种（检索摘要归纳）：

| 型 | 结构 | 例子 |
|---|---|---|
| 应用构想 | 技术原理与适配性 → 现实困境 → 应用框架与场景 → 实施路径与保障 | 《联邦学习技术在税收风险管理中的应用构想》（税务研究 2024 年第 11 期） |
| 逻辑—困境—路径 | 理论、历史、实践三重逻辑 → 现实困境 → 实现路径 | 《人工智能赋能预算治理现代化的三重逻辑》（财政监督 2026） |
| 风险—规制 | 技术带来的几类困境 → 规制方案 | 《人工智能在税务领域应用中的风险及规制》（税务研究） |
| 框架—指标 | 维度 → 指标 → 可选的测算 | 数字政府评估体系一类（这一型已经是"四 + 二"） |

### 2.3 它们成批出现，紧跟热词

- 《税务研究》2026 年第 2 期，一期发了 5 篇"投资于人"。这个词 2025 年 3 月写入政府工作报告，相隔约 11 个月。
- 《税务研究》2023 年第 10 期，一期发了 3 篇"人口高质量发展"。这个提法出自 2023 年 5 月的中央财经委员会会议，相隔约 5 个月。

这是专题组稿的节奏：**讲道理文是追新热词最快的文体**。冲击回归文要等试点落地、数据出来，通常要两三年。

### 2.4 刊物口径（检索摘要，需核）

| 刊物 | 对非实证稿的态度 |
|---|---|
| 税务研究 | 接受度最高，"精粹的短篇尤为欢迎"，1 万字以内 |
| 财政研究 | 有"厅局长论坛""改革探讨"等栏目，官员政策稿有固定出口 |
| 财政科学、财政监督 | 贴近决策；《财政监督》2026 年重点选题第 8 项是"人工智能赋能财政管理" |
| 宏观经济管理 | 收政策设计，**不收**"公式模型、理论阐述、研究综述"，要"观点鲜明、论据充足"，关键词不得出现"问题与对策" |
| 中国行政管理 | 综合板块收 4000—6000 字的短政策稿，学术板块约 1 万字以上 |
| 电子政务 | 常发"技术 → 治理"的框架稿 |
| 探索与争鸣、人民论坛·学术前沿 | 收"重大现实问题"的思想稿，实际看重专题组稿和作者身份 |
| 公共管理学报 | 要"以事实为基础的经验研究"，纯讲道理基本不收 |
| 管理世界、经济研究 | 编辑部口头上反对"重模型、轻思想"，但实际刊出的非实证稿极少，几乎都出自资深学者 |

## 三、五道门：评估清单

每道门打 0—2 分：0 = 没有，1 = 有但弱，2 = 过关。

### 门 1：痛点门（C）——国家是不是已经承认这是个难题？

- **测试**：有没有中央文件、部委答记者问的原话承认"难、不敢、不会、落地难"？有没有一个"条款都有了、问题还在"的矛盾数字？
- **打分**：
  - 2 分：文件点名，再加一个矛盾数字。
  - 1 分：只有热词，没有承认难题的原话。
  - 0 分：痛点是作者自己说的，或者痛点就是"还没用某技术"。
- **和冲击回归文的区别**：冲击回归文的 C 可以后补；这里不能，整篇文章都长在痛点上。而且越新越好，旧词新引不加分（见 `06_最新C词_四中全会与十五五.md`）。还要注意口号的保质期，挂靠的提法过期，文章就跟着过期。

### 门 2：来头门（A）——借来的东西有没有分量？

- **测试**：A 在原领域是不是成熟、有名、可以引用？现实中有没有别国、别行业、别的部门已经在用的先例？
- **打分**：
  - 2 分：原领域有经典或最新的权威成果，另外至少有一个现实先例。
  - 1 分：只有原领域依据，没有现实先例。
  - 0 分：A 只是一个时髦名词。
- **先例是把双刃剑**：现实先例越像，越能证明"这事可行"，也越会吃掉新意。找到先例以后，要逐条写清楚自己比它多了什么，以及在中国的场景里它为什么不够用。

### 门 3：映射门（A→B）——借的是道理，还是名字？

这是政策假说文最容易注水、也最能拉开差距的一道门。

- **测试 1：去名词**。把借来的名词全删掉，看设计还剩什么。如果剩下的是"加强信息化、全过程留痕、数据共享"这类本来就有的东西，就是只借到了名字。
- **测试 2：看关系**。映射的是部件的外观（"都有一条线连过去"），还是原领域里那套因果关系（"为什么会出问题、为什么这样能治"）？认知科学的结构映射理论（Gentner 1983）说，好类比映射的是关系系统，不是属性；关系连成的体系越完整，类比越有力。
- **测试 3：看新预测**。借了它，能不能推出一个不借它就想不到、而且能被推翻的预测？中文科层制研究早就用白话描述过"层层传导中的信息异化""隔热层""信息深井"，经济学也早有"控制损失随层级连乘衰减"（Williamson 1967）。借来的结构要比这些多给出一点东西，不然审稿人会问：这跟委托代理、多任务激励有什么区别？
- **测试 4：主动交代不像的地方**。科学哲学把类比分成三部分：正类比（像的地方）、负类比（不像的地方）、中性类比（还不知道像不像的地方，Hesse 1966）。最有价值的是中性类比，因为它能变成待检验的预测；最危险的是藏起来的负类比。最关键的那条负类比要自己先说出来，比如"人会预期审查、事先塑造材料，神经元不会"。
- **打分**：
  - 2 分：前三项都过，测试 4 也做了。
  - 1 分：过了测试 2，但测试 1 或测试 3 没过。
  - 0 分：只借到名字。
- **顺带一个排雷**：撞名的概念要主动切割。比如中文公共管理里的"注意力分配"来自西蒙的有限理性传统，和 Transformer 的注意力机制不是一回事。

### 门 4：落地门（D）——实务部门拿去，能不能直接改条款？

- **测试**：
  - 能不能写成一页条款、一张流程图、一份模板？
  - 有没有和现行文件逐条对照，说清"增补了什么"？
  - 设计的细节够不够回答四个问题：谁来认定、凭什么证据、什么时候触发、怎么复核？
  - 方向是不是"顺着改革往前多走半步"，而不是推倒重来、和"加强监督""防范风险"唱反调？
- **打分**：
  - 2 分：有制品、有逐条对照，方向也顺。
  - 1 分：只有原则。
  - 0 分：对策只是"加强、完善、健全"。
- **最好讲的设计，能同时服务政策的两头。** 政策常常两头同时加码，比如一边要"鼓励探索、宽容失败"，一边要"从严监管、防范风险"。只服务一头的设计，会被另一头的审稿人挑剔；能让两头都受益的设计（比如把正常失败和失职分开，既保护前者又约束后者），天然对上"高度统一"这类话语。
- **小心撞上中央明确反对的东西。** 凡是涉及记录、台账、材料的设计，都要先排除"痕迹主义""过度留痕"的嫌疑。说法上应该是"少留痕、留对痕"，并算清楚它比现状省了多少事。

### 门 5：支撑门——拿什么替代数据？

- **测试**：至少要有一条腿，可以是：文本编码（造指标）、公开案例、情景实验、玩具模型（造模型），或者对已有实证结果的重新检验。
- **打分**：
  - 2 分：两条腿，或者一条能直接检验核心命题的腿（比如实验）。
  - 1 分：一条描述性的腿（文本或案例）。
  - 0 分：只有论述。
- **证据阶梯**（设计科学的评估思路，从便宜到贵）：
  1. 有据论证
  2. 形式模型的比较静态
  3. 仿真
  4. 情景实验（材料相同、组织方式不同）
  5. 专家评审
  6. 脱敏的真实流程演示
  7. 试点

  往上走一级，能投的刊物也往上走一档。还要说清"和什么比"，基线一般是现行文件加现行做法。
- **试一句"什么结果会让我放弃这个命题"**。说不出来，就还不是命题。

### 附加检查：排重（也打 0—2 分）

- **测试**：最近两三年，同刊同题有没有人做过同一个病因？
  - 要查四类来源，不只查期刊：
    - 行业协会和咨询机构的研究报告；
    - 律所文章；
    - 相邻领域的现行做法（比如担保、银行里已经在用的类似制度）；
    - 国外的成文制度。
  - 政策假说文最容易撞车的不是论文，是这些"非论文"。
- **打分**：
  - 2 分：逐条比过，写得出自己多了什么，定位是"补充"，也就是能解释已有结果为什么不稳定，或者能给出调节变量。
  - 1 分：知道有直接前作，但没逐条比。
  - 0 分：没查，或者和前作重复。

### 总分怎么读

五道门加排重，共六项，满分 12 分。

| 总分 | 判断 |
|---|---|
| 0—4 | 典型的讲道理文，只适合实务刊物、内刊、征文；或者重新选题 |
| 5—7 | 能讲，但还投不了中上刊物；先补映射和支撑 |
| 8—10 | 能投财政研究和公共管理类核心刊物 |
| 11—12 | 有冲顶刊的底子，但顶刊仍要求至少一条硬腿：模型，或实验、实证 |

这五道门和方法论文献是对得上的：
- 门 1、门 3 对应概念类论文的"是什么、怎么样、为什么、在什么条件下"（Whetten 1989）。
- 门 3 对应结构映射理论。
- 门 4、门 5 对应设计科学的要求：设计出一个"制品"，并且做评估（Hevner 等 2004）。
- 门 2 和排重对应设计科学的贡献定位（Gregor 和 Hevner 2013）。设计科学按两个维度给贡献分类：问题新不新，方案成不成熟。
  - 把成熟方案搬到新问题上，叫"挪用"（exaptation）；
  - 给老问题找新方案，叫"改进"；
  - 老方案用在老问题上，叫"常规设计"，不算研究贡献。

  这里有个容易踩的坑：借的东西在原领域成熟，并不说明自己是挪用。要看目标领域是不是早就有同样的原则。如果早就有，比如"按决策当时的信息审过程、不以结果论"，在信托法和公司法里已经成文，那么最多只能主张"改进"，而且要把多出来的要素一条条列出来。

## 四、好不好写：难度从哪来

1. **数据门槛没了，说服门槛升高了。** 冲击回归文靠表格说话，审稿人挑识别；政策假说文靠论证说话，审稿人挑的是"你凭什么这么说"。门 3 和门 5 回答的就是这句话。
2. **腿数决定天花板。**

| 腿 | 对应四分类 | 大致天花板 |
|---|---|---|
| 只有论述 | 四 | 税务研究、财政监督、财政科学、电子政务、学报、征文 |
| 论述 + 文本或案例 | 四 + 二 | 财政研究、中国行政管理、宏观经济管理（要可操作的设计） |
| 论述 + 模型 | 四 + 三 | 财贸经济、经济学动态 |
| 论述 + 实验或实证 | 四 + 一 | 公共管理学报、管理世界；经济研究很少见 |

3. **时效比冲击回归文更要紧。** 热词出来后的 5—11 个月是专题组稿的窗口。过了窗口，同一个热词下讲道理文的边际价值迅速下降。冲击回归文正好错开这个窗口，所以两种文体可以接力：先用政策假说文占住说法，再等数据做实证。
4. **作者身份更要紧。** 部委、财政厅、基金管理机构的作者写"思考""建议"，天然有说服力；第二节已经看到，中上刊物里的讲道理文几乎都出自有身份的人。年轻作者有两条替代路：一是长腿，二是找实务部门的合作者，再附一个脱敏案例。

## 五、常见死法

1. **"问题"就是"没用我的技术"**：痛点的定义里已经装着解法，循环论证。这是 `01_文章四分类.md` 里讲道理型的第一个露馅点。
2. **技术决定论**：把技术能力直接当成治理能力，不讨论组织因素会不会把效果吃掉。
3. **名词堆砌**：赋能、重塑、闭环、全链条、全生命周期，堆满了，却没有一个机制能被推翻。
4. **映射只借到名字**：一做去名词测试就空了；没有"源域—目标域"对照表，也没有命题。
5. **对策泛化**："是什么—为什么—怎么办"三段论加上"加强、完善、健全"，实务部门读完不知道明天该改哪一条。
6. **缺制度细节**：说不清谁来认定、凭什么证据、什么时候触发、怎么复核。
7. **不和已有文献对话**：比如容错纠错、避责、多任务激励、职业顾虑都有大量研究，文章却假装是第一个提出问题的人。
8. **只讲好处，不讲成本和反向路径**：审稿人会替你补，补出来的往往是"国有资产流失""加重基层负担"。
9. **挂靠的口号过期了。**
10. **反过来的死法：过度谨慎。** 满篇"不能""尚待""有待检验"，读起来像研究计划书，审稿人找不到你到底主张什么。边界条件要写，但要集中写一次，最好改写成可检验的"成立条件"。

## 六、成功的样子：审计"免疫系统"论

这是跨学科类比变成官方话语、又进了顶刊的少数案例（时间线来自检索摘要）：

| 时间 | 事件 |
|---|---|
| 2008 年 3 月 | 审计长刘家义在中国审计学会讲话中，提出审计是国家经济社会运行的"免疫系统" |
| 2008 年 | 写入审计署《2008 至 2012 年审计工作发展规划》 |
| 2008—2009 年 | 审计科研所在全国审计系统组织"免疫系统"征文，收稿 582 篇 |
| 2009 年 | 写入国务院年度审计工作报告 |
| 2012 年 | 《论国家治理与国家审计》发表于《中国社会科学》第 6 期：国家审计是"内生的具有预防、揭示和抵御功能的'免疫系统'"，并给出三个"决定"的命题链 |
| 2018 年以后 | 官方主表述改为"审计是党和国家监督体系的重要组成部分"，这个提法的保质期大约十年 |

它为什么成功：

- **映射的是功能，不是外观**：免疫的防御、自稳、监视，对应审计的预防、揭示、抵御。
- **改写了对象的身份**：审计从"外部检查工具"变成"治理系统的内生子系统"。
- **有命题链**：三个"决定"可以往下推。
- **有工具包**：规划、征文、项目计划管理都能用上。
- **四个字就能当口号。**
- **作者就是审计长。**

前五条年轻作者都能学，第六条学不了，只能用"腿"和实务合作者来替代。

另外几个可以对照的案例：
- "财政是国家治理的基础和重要支柱"：先有中央文件，后有学者阐释。
- "城市大脑"：企业家提出，地方先建，再出文件。
- "数字孪生城市"：部属智库首倡，国家级新区试点，再写入"十四五"规划纲要。

几个案例有一个共同点：**都有一个能看得见的东西落了地**。

## 七、怎么用

拿到一个政策假说题目，按顺序问五句：

1. 文件原话里有没有承认这个难题？能不能找到"条款都有了、问题还在"的数字？
2. 借来的东西去掉以后，还剩什么？借了它，能推出什么不借就想不到的预测？
3. 能不能写成一页条款，并和现行文件逐条对照？
4. 最便宜的一条腿是什么？（通常是文本编码或情景实验）
5. 同刊最近有没有人做过同一个病因？

## 局限

- 刊物分布来自五个热词的检索结果，不是全部文章。"阐释综述"由子代理按摘要编码，个别可能有出入。
- 刊物口径、案例时间线和题名多数来自检索摘要（这一轮网页正文大多抓取不到），引用前要在知网或原网页核对。
- 五道门是从方法论文献和少数案例归纳出来的，还没有用一批政策假说文逐篇检验过。下一步可以仿照财税 45 篇的做法，从《财政研究》《宏观经济管理》《电子政务》里抽一批制度设计类文章逐篇打分，看分数和刊物层级、被引次数是否对得上。
