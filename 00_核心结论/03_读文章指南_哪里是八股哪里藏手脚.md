# 读文章指南：哪里是八股，哪里藏手脚

> 以冲击回归型文章为对象，以余明桂等（2026，《经济研究》）为主要例子。
> 总原则：**别读字，看表里的数。** 八股文字每篇都一样，读了没有信息；露馅只能露在每篇自己的数字和定义上。

## 一、扒一篇文章的节奏（十几分钟）

1. **引言、理论、模型设定精读**：看它把什么偷换成了什么。
2. **基准回归和平行趋势图细看**：系数几颗星、选择效应多大、事前几期是不是真平。
3. **后面几节只扫表格找矛盾**：安慰剂、机制、进一步分析。
4. **政策建议**：看越界了多少。

## 二、逐节：八股 vs 藏手脚

| 部分 | 八股（可跳过） | 藏手脚的地方（必看） |
|---|---|---|
| 引言 | 全会、"人工智能+"开头；"首次聚焦"；三条贡献"拓展了三支文献" | 痛点有没有一个数字支撑；政策目标是不是被当成政策事实 |
| 研究背景 | 科普算力、芯片、制度沿革 | 背景里的图表常暴露口径（如 2010 年就有 13 万件"AI 专利"） |
| 理论与假说 | 名牌理论 + 装饰性公式 + H1/H2a/H2b | 见第三节 |
| **模型设定** | 回归方程、控制变量、固定效应、"变量定义见附录" | **五个关键选择**，见第四节 |
| 基准回归 | "显著""具有重要现实意义" | 几颗星；不加固定效应时系数多大（选择效应）；对数换算是否成立 |
| 平行趋势 | "事前各期均不显著" | 事前几个点是不是同号、同大小；建成当年是否就跳 |
| 稳健性 | 换方法、换样本、PSM、SDID，全在附录 | 只回答"换个算法还在不在"，回答不了"测的是不是对的东西" |
| 异质性 | "民营显著、国企不显著" | 一组显著一组不显著 ≠ 两组有差异；预期是事后写的 |
| 机制 | "与理论预期一致" | 安慰剂/对照组的**系数大小**，别只看显著性；机制变量量级能否对上 |
| 进一步分析 | 质量、扩散、效率三件套 | 见第五节 |
| 政策建议 | 两三页，回扣中央文件 | 有没有建议了没检验过的东西；有没有和结果相反 |

## 三、理论节：给回归结果配理由，不是推导出回归结果

以余明桂那篇为例，三段理论各有分工：

| 段落 | 用的理论 | 回答的问题 | 服务哪张表 |
|---|---|---|---|
| 第 1 段 | 常识：C 需要 B | 为什么研究这个 | — |
| 第 2 段 | 实物期权 | 企业为什么**敢**投（供应稳了不观望） | 应对"为什么不租商业算力" |
| 第 3 段 | 要素互补 | 企业为什么**愿意**多投钱、多招人 | 表 3（研发投入、研发人员） |
| 公式（1）—（6） | 柯布—道格拉斯求导 | 把第 3 段翻译成数学 | 让审稿人看到"有推导" |

**写作顺序和实际顺序是反的**：写出来是"理论 → 假说 → 实证"，实际是"先跑出结果 → 给每个结果配理由 → 用公式串起来"。

来源判断：
- 研发投入、人力资本是**领域标配**：数据现成、故事好讲，也是审稿人必问的"渠道"。
- 要素互补是数字化、IT 研究的**常年固定搭配**。
- 实物期权是作者**加的新意**，引的 Alessandria 等（2025）讲的是中美贸易政策，有点硬凑；后面公式里也根本没有不确定性。

假说结构 H1 主效应 + H2 机制渠道是通用八股。问题不在有假说，而在每个假说里最关键的那半句（"通过改善算力供给""因为互补"）没被数据检验。

**自己写的时候**：先定后面要报告哪几张表，每张表倒推一个理由，找一个和 A 性质相符的理论；只写有结果支撑的机制，别硬塞期权、人力资本。

## 四、模型设定：写法是八股，内容决定一切

这一节最容易被跳过，偷换多半就发生在这里。盯住五个选择：

1. **处理变量怎么定义（最要紧）**：余明桂把"企业所在省份当年有没有建公共智算中心"当处理。武汉建了中心，恩施、十堰的公司也算被处理；全文不知道哪家企业真用过算力，脚注里承认了。**标题说"公共算力供给"，这里定义的只是"省里有没有挂牌"。**
2. **因变量怎么取**：ln(1+AI 专利数)，大部分是 0，系数不能读成百分比，正文却说"增加约 2%"；"AI 专利"是 IPC 大口径。
3. **聚类层级**：聚类在省份，只有三十来个群，显著性容易虚高。财税 45 篇里聚类低于处理层级的现象很普遍。
4. **固定效应和控制变量的取舍**：只放四个基本控制变量，还拿一篇美国税改论文给"用了年份×行业固定效应"背书。
5. **同时控制一个"预设不显著"的对照**：控制"商业智算中心"，为"公共有用、商业没用"铺路。

读这一节只问三句：处理变量和标题概念是不是一回事？因变量是不是换了更易显著的口径？关键设定有没有理由、有没有展示换设定的结果？

## 五、"进一步分析"三件套：把薄结果撑成体系

```
核心结果：AI 专利数量涨了（薄）
→ 审稿人：是不是水专利？ → 补"质量"（IPC 分类号分散度）
→ 政策热词：溢出带动     → 补"扩散"（发明人重叠）
→ 收尾：对经济有什么用？ → 补"TFP"（10% 显著）
```

- **质量**：分类号挂得越分散就算质量越高，分类号多由审查员和代理人给出。
- **扩散**：AI 专利一多，"AI 发明人"名单自然变长，出现在非 AI 专利上的比例机械上升，不需要任何扩散。小节开头还引了领导人讲话当"理论依据"。
- **TFP**：新三板小公司的中间投入是拼出来的，两个结果都只有一颗星，逻辑还跳得太远。

判断标准：**这个指标是不是在"量"涨了之后必然跟着涨？** 如果是，就是同一个结果换了件衣服。

## 六、识破清单：扫表时找这些数

| 找什么 | 余明桂一篇里的例子 |
|---|---|
| 核心系数几颗星、几个聚类 | 0.019（0.011），一颗星，三十来个省级聚类 |
| 不加固定效应时系数多大 | 0.076 → 0.022，选择效应巨大 |
| 事前趋势是不是同号同量级 | 事前三期约 −0.020、−0.015、−0.019 |
| 因变量均值和对数换算 | 常数项 0.19，至少七成观测是 0，"约 2%"不成立 |
| 安慰剂系数是不是其实不小 | 非 AI 专利 0.030 > AI 专利 0.019 |
| 机制变量量级能否对上 | 研发人员 +9%，研发投入 +2% |
| 背景图表暴露的口径 | 2010 年就有 13 万件"AI 专利" |
| 样本构成 | 5023×8 = 40184，平衡面板只剩幸存者 |
| 按定义应被吸收的系数 | 城市×年份固定效应下仍估出省级处理的系数 |
| 附录依赖程度 | 处理组名单、描述统计、全部稳健性都在附录 |

财税 45 篇里额外常见的几类：**摘要数字和正文表格对不上**、**经济意义换算错一个数量级**、**同一张表不同设定系数完全相同**、**稳健性全部"备索"**。核对这几项，比追问"是不是蹭热词"更容易抓到实打实的问题。
