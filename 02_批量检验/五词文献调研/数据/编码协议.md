# 知网导出逐篇编码协议（五个选题词）

## 目的与立场

我们准备投的也是这些期刊（经济研究、管理世界、世界经济、中国工业经济、财贸经济、财政研究、税务研究，以及经济学季刊、金融研究、数量经济技术经济研究）。
这次编码的目的是建立**"同刊基准线"**：这些期刊实际接受了什么样的 A（冲击）、什么样的 C 指标、贴合到什么程度。
**只记录，不挑毛病。** 不要写"指标不够好""显著性低"之类的评价；贴合度一栏只是客观记录"实测指标离标题概念有多远"，用来说明期刊能接受到什么程度。

## 依据

只依据导出文件里的题名、关键词、摘要。摘要没写的，写"摘要未给"，不要编造。
政策起始年如果摘要没写、但你有把握知道，写"约YYYY（常识）"；没把握就写"摘要未给"。

## 逐篇字段（输出为 TSV，制表符分隔，第一行为表头，UTF-8）

| 列 | 说明 |
|---|---|
| 编号 | 输入文件里的编号，如 SB-001 |
| 题名 | 原题名 |
| 第一作者 | |
| 期刊 | |
| 年期 | 如 2025(3) |
| 文章类型 | 冲击回归 / 其他实证 / 模型模拟 / 测度 / 阐释综述 |
| A | 冲击或处理变量，用原文的叫法，写清是什么政策或事件；非冲击实证写核心解释变量 |
| A起始年 | 政策或事件开始的年份 |
| A类型 | 全国统一政策 / 分批试点或分地区推开 / 地区强度差异 / 市场或企业事件 / 技术冲击 / 外国政策 / 宏观或信息冲击 / 自然或历史 / 连续变量（非冲击） / 无 |
| 识别方法 | 多期DID / 强度DID / 普通DID / 三重差分 / 断点 / 群聚 / 工具变量 / 事件研究 / 田野实验 / 合成控制 / 局部投影或VAR / 一般回归 / 结构模型 / 无 |
| 标题C | 标题或摘要宣称研究的结果概念 |
| 实测C指标 | 摘要里给出的具体被解释变量 |
| 数据来源 | 如 CFPS、CHARLS、税调、上市公司、城市统计年鉴、自建文本 |
| 贴合度 | 高（实测就是标题概念本身）/ 中（常见代理）/ 低（距离较远）/ 摘要无法判断 |
| 热词 | 题名、关键词、摘要中出现的政策热词，如投资于人、预期管理、生育友好、房地产高质量发展、社保可持续、共同富裕、高质量发展、统一大市场等；没有写"无" |
| 效应数字 | 摘要里给的系数、百分比；没有写"无" |
| 备注 | 机制、异质性或其他值得记的一句话 |

## 汇总文件（Markdown）

1. **篇数**：文章类型 × 期刊的计数表；冲击回归共几篇。
2. **A 清单**：只列冲击回归和其他实证。按 A 起始年从新到旧排列，每行写 A、篇数、编号、期刊年期。**单独列出起始年在 2022 年及以后的冲击。**
3. **A 类型分布、识别方法分布**（计数表）。
4. **C 指标清单**：按类别分组（实际行为或结果 / 意愿或态度 / 企业财务 / 宏观或地区加总 / 文本或指数 / 其他），每组列指标、编号、贴合度。另外单独举 3—5 个**"贴合度低也发了"**的例子，写清期刊。
5. **空白**：
   - (a) 对照下面给你的"候选新政策清单"，逐条写出本导出里有没有人用它当 A（有就写编号，没有就写"未见"）；
   - (b) 本主题最直接的 C 指标里，哪些没人用。
6. **值得精读全文的 5—8 篇**：最接近"财政学视角 + 新冲击 + 能做 DID"的，写编号、题名、理由（一句话）。

## 注意

- 一篇文章同时有多个冲击时，A 写主冲击，其余写进备注。
- 阐释综述类只需填编号、题名、作者、期刊、年期、文章类型、热词，其余写"—"。
- 汇总的计数要和 TSV 一致，写完后自己核对一遍。
