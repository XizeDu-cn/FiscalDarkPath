# 财税 45 篇：热词 C 从哪来，最近什么词好写

> 依据：45 篇全文逐篇编码中的“热词来源”字段（`02_批量检验/财税45篇_逐篇编码.md` 第 4 项），以及 2026 年七刊 258 篇冲击回归目录。十五五纲要的财税要点对照了公开报道（见文末来源）。

## 二、规律

**1. 热词几乎全部来自“最近一次全会”，而且追得很快。**
三中全会《决定》是税收类文章的主引源，四中全会和十五五是最新一层。2026 年 5—6 月发表的《经济研究》文章（ERJ-017、020、023）已经在引 2026 年 3 月才通过的十五五纲要，ERJ-024、040 引了 2026 年政府工作报告。这些文章的收稿都在更早的时候，说明**热词是在修改或定稿阶段补进引言的**，不是选题时的出发点。

**2. 税收文章都在抄同一句话。**
“健全有利于高质量发展、社会公平、市场统一的税收制度”（三中《决定》，十五五纲要沿用），在 ERJ-017、ERJ-023、WE-038、CMJJ-023、FISC-015 里几乎原样出现；ERJ-020、CMJJ-023 再加一句“全面落实税收法定原则，规范税收优惠政策”。**税收类引言的第一句是可以直接模板化的。**

**3. 热词只出现在两个位置：引言第一段和政策建议。**
实证部分几乎不出现。标题另走“口号化”路线：“寓治理于平稳”“春风化雨育新苗”“从‘援助之手’到‘市场之手’”“从‘激励错配’到‘权责适配’”。

**4. 期刊差异非常明显。**

《经济研究》和两本财税刊物几乎篇篇挂顶层文件；《世界经济》最克制，研究扫盲、疫苗、名额分配的几篇只讲学术问题。

## 三、最近什么词好写：只看财税领域

“好写”要同时满足两条：**文件里有这个词**，**有分批落地的政策可以做 DID**。按这两条分成三档。

### 红海：已经写满，再写很难出新（2026 年七刊里已有 3 篇以上）

| 主题 | 2026 年七刊篇数 | 文章 |
|---|---:|---|
| 地方债、化债、融资平台、预算约束硬化 | 8 | WE-048，MWM-007、032，CIE-007、014、031，FISC-014、024 |
| 社保降费、缴费基数 | 6 | ERJ-006、023、041，MWM-029、030，CMJJ-046 |
| 研发费用加计扣除 | 4 | TAX-001、003、007、010 |
| 省直管县 | 4 | CMJJ-016，FISC-001、005、009 |
| 金税、数电发票、征管数字化 | 3 | ERJ-017，TAX-005，FISC-025 |
| 留抵退税 | 3 | MWM-031，TAX-008，FISC-004 |
| 税收“放管服” | 3 | CMJJ-001、023，TAX-004 |

### 正在热，还没写满（只有 1—2 篇）

| 热词 | 已有文章 | 可做的冲击 |
|---|---|---|
| **投资于人** | FISC-017（以它为 C），FISC-011、012 挂在引言 | 义务教育、医疗央地分担改革，民生支出比重变化 |
| **财政科学管理、零基预算** | ERJ-034（预算一体化） | 零基预算改革分省推开 |
| **增加地方自主财力** | ERJ-024 | 转移支付分类改革 |
| **预期管理** | FISC-003 | 政策发布会、财政部新闻 |
| **统一大市场、反内卷** | FISC-024 | 招商引资税收返还清理、税收优惠清理 |
| **生育支持** | TAX-006 | 地方育儿补贴、个税专项附加扣除提标 |
| **数据财政** | MWM-021 | 公共数据授权运营试点 |

### 蓝海：十五五纲要写了，这批 45 篇几乎没人碰

十五五纲要把现代财政制度拆成预算、税收、财政体制、政府债务四块，下面这些词都在里面，但本批 45 篇基本空白：

| 热词（十五五纲要表述） | DID 可做性 | 说明 |
|---|---|---|
| 推进**消费税征收环节后移并稳步下划地方** | 低（尚未全面落地） | 可以先做“预期、信号”类，或用已后移的品目 |
| **提高直接税比重**；完善综合与分类相结合的个税，**逐步扩大综合征收范围** | 中 | 可用历次个税改革（2019 已被 TAX-006 等使用） |
| 健全**经营所得、资本所得、财产所得**税收政策 | 低—中 | 数据难拿 |
| **研究同新业态相适应的税收制度** | 中 | 平台经济涉税信息报送、跨境电商税收 |
| **优化共享税分享比例** | 低 | 更适合做模型或模拟 |
| **健全支出标准体系**，加强**预算绩效管理** | 中 | 分地区绩效管理改革 |
| **合理提高公共服务支出占财政支出比重** | 中 | 与“投资于人”连用 |
| **完善增值税留抵退税政策和抵扣链条** | 中 | 增值税法 2026 年施行（FISC-023 已做“立法信号”） |

另有两个 2025 年的民生财政政策，我判断会很快被写，但没有逐条核对原文：**育儿补贴制度**（全国统一，但此前有地方先行）和**学前教育收费减免**。全国统一实施的政策做不了标准 DID，要找地方先行的差异。

## 四、一句话

**热词 C 基本来自“最近一次全会 + 最新的规划纲要 / 政府工作报告”，在修改阶段补进引言第一段；财税类最好写的，是十五五纲要里写了、又有分批试点可做 DID 的词，比如投资于人、零基预算、地方自主财力、新业态税收。已经被写满的，是化债、社保降费、加计扣除、省直管县、留抵退税。**
