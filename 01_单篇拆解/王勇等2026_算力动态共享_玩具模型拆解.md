# 《算力资源的动态共享：价格形成与政策分析》玩具模型拆解

> **论文**：王勇、傅芳宁、李红军，《算力资源的动态共享：价格形成与政策分析》，《经济研究》2026 年第 5 期，第 49—72 页。
> **类型**：造模型型（玩具模型）。原文在 `papers/01_AI与算力宏观_第一批/`。
> **说明**："玩具模型"指模型小到只能演示作者已经想好的结论，本身没有能力告诉你新东西；不涉及对作者的学术不端指控。

## 一句话本质

**作者自己定了一个"三户人家报价分水"的小游戏，把游戏规则里的两个数改了好听的名字，然后宣布"发现"了游戏规则本身，再套上"算力、共享经济、马歇尔理论"的外衣。**

## 大白话比喻：三户人家合用一口井

1. **定规则**：每户"觉得水值多少"就报多少，水价 = 三户报价的平均数，报得高的多分水。规则是拍脑袋定的，不是观察出来的。
2. **给参数起名**：规则里有两个数，"用水能赚多少钱"起名"共享动力"，"挪水麻不麻烦"起名"共享压力"。
3. **求导出"命题"**：用水越赚钱的人家越愿出高价，水价就越高。相当于"越饿的人越想吃饭"，是规则写好的。
4. **动机和模型对不上**：开头说研究这个是因为用水"时多时少"，旱季借、雨季卖；模型里根本没有旱季雨季，需求从头到尾是死的。
5. **"借"其实是"卖"**：脚注写明借出去的水不用还。
6. **政策分析是教科书结论**：只补贴买水的人、井就这么大，水价自然涨；政府按固定低价卖公家井的水，市场价自然被压住。
7. **模拟靠凑数**：初始水价 0.4 用"每投 1 元带动 3 元 GDP"硬换算出来，画 100 期曲线叫"动态演化路径"。
8. **建议和游戏无关**：结尾建议支持国产水泵（华为昇腾、寒武纪）、搞"东水西调"（东数西算）。

## 对应原文

| 比喻 | 原文 |
|---|---|
| 三户人家 | 数值模拟 N=3：低、中、高算力禀赋企业，禀赋 (2, 5, 15) |
| 报价规则 | 企业报价 b = p + η(ρ−p)/v，市场价 = 平均报价（式 4、式 7） |
| 两个参数 | 算力收益系数 μ 改名"共享动力"，调整成本系数 η 改名"共享压力" |
| 时多时少 | 摘要以"需求峰值租入、谷底租出"为动机，但模型没有任何随机需求 |
| 借了不还 | 脚注：不考虑共享时长，共享后不回到禀赋 |
| 补贴抬价 | 算力券只补买方、总量不变，价格上升（定理 2） |
| 公家井 | 公共算力按固定价 θm 供应，市场价被封顶（定理 3.1） |
| 凑数 | 初始价 p0 = 1.2/3 = 0.4；损耗系数 k = 0.6 由丢包率 0.0758% 与"0.1% 丢包 → 50% 算力损失"拼出；α = 0.5 借自一篇金融科技论文 |
| 无关建议 | 华为昇腾、寒武纪、东数西算、国产算力生态 |

## 套路总结

```
选热词：算力、共享经济
→ 搭一个极简规则（3 个主体、线性报价、价格取平均）
→ 给规则里的参数起概念名（共享动力、共享压力）
→ 对线性式求导，得到"命题"
→ 加两个政策：补贴只补买方、公共供给固定价 → 教科书结论
→ 数值模拟：参数东拼西凑，画 100 期曲线
→ 贡献写成"创新和发展马歇尔市场动态理论"
→ 政策建议写国产芯片、东数西算
```

**识别方法**：问一句"动机里那个关键现象（需求波动），模型里有没有？"再问一句"换成水、电、停车位，结论还成立吗？"两个答案都是"没有 / 成立"，就是玩具模型。
