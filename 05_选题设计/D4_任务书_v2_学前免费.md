## 一、主设定（起点设定，可按通用规则 v2.1 调整）

| 项目 | 设定 |
|---|---|
| 冲击 A（主） | **A2 地方先行免费学前教育**（各省市自行出台的学前免保教费政策，交错实施）。论文里统一叫"**地方先行免费学前教育**"。2025 年秋季全国学前一年免保教费（国办发〔2025〕27 号，标题与文号需核实）**不做主冲击**，只作"后轮"放进一步三（事后只有 1 期） |
| 分析单位 | **地级市 × 年**（县级数据太散，不用县级做主样本） |
| 处理变量 | **Treat × Post**：地市（或其所在省份整体）开始实行学前免保教费的当年秋季学期起，Post=1；按"开始实施年份"定义处理批次，交错 DID。秋季起实施的，当年记 0.5 还是 1：**一律从下一年记 1**（学年口径，当年不算） |
| 处理强度（备选，见第七节自动检查） | **免费覆盖年数**：0、1（仅大班）、2、3（三年全免）÷ 3，连续变量 × Post |
| 参照年 | 事件研究以**实施前一年（t=−1）**为基期，窗口 t=−5 至 t=+5，两端合并 |
| 主样本 | 全国地级市，**2012—2023 年**（数据能到 2024 就延到 2024，不再往后） |
| 主模型 | `reghdfe C Treat_Post 控制变量, absorb(城市 年份) vce(cluster 城市)`；交错 DID 稳健估计量用 **CS（csdid）** 和 **Sun-Abraham（eventstudyinteract）**，事件研究图用 CS |
| 控制变量 | 人均 GDP（对数）、财政自给率、城镇化率、第二产业占比、人口密度、出生人口（对数，**3—5 年前**的出生数），全部滞后一期 |
| 主结果 C | **C1 学前三年毛入园率**（在园幼儿数 ÷ 3—5 岁人口；3—5 岁人口用对应年份往前 3—5 年出生数之和代理）。表 2 同时报 **C2 在园幼儿数（对数，控制出生人口）**作第二列 |
| 备选 C（见第七节自动检查） | **C2' 大班在园数 ÷ 5 年前出生数**（离"免费大班"最近）；若无大班口径，用在园幼儿数（对数） |

**故事主线（据此排表）**：

> 地方先行免费学前教育后，试点地区**入园率上升、在园幼儿数相对稳住**。家庭保教费负担下降、地方学前财政投入上升，说明"钱"是渠道；普惠园和公办园占比上升，说明学位供给扩张是渠道。效应集中在财政自给率低、农村占比高、基期入园缺口大的地区。进一步看，师幼比和幼师学历改善（质量），有 3—6 岁孩子的母亲就业上升（家庭）；三期行动计划（前轮）和 2025 年全国免费（后轮）方向一致。

民办园若减少，**不藏**，正面写成"普惠转型/结构调整"，放异质性表（表 8）。

## 五、怎么写结果（同刊措辞，数字照表）

### 5.1 措辞模板

| 情况 | 写法 |
|---|---|
| p < 0.01 | "在 1% 水平上显著为正，表明……" |
| p < 0.1 | "在 10% 水平上显著，表明……"（**照写"显著"**，同刊惯例） |
| 方向对、不显著 | "系数为正但不显著，说明免费政策的作用存在边界 / 仍有待进一步释放" |
| 方向相反 | 照实报；能在故事里解释就解释（如民办园减少 = 普惠转型），解释不了写"可能的原因是……" |
| 异质性某组显著、另一组不显著 | "**上述效应主要集中在××地区**"，并报组间差异检验 p 值 |
| 机制变量显著 | "这验证了家庭成本下降 / 学位供给扩张渠道" |
| 只有省级或一年截面 | "受数据可得性限制，本文采用……"（同刊有先例，照写） |

### 5.2 不越的线（只有这三条）

1. **正文写的每个数字，都能在表里找到。**
2. **不改数据、不删样本去凑显著。** 样本筛选只按第一节写死的规则；试点年份按第二节来源定一次，不为显著性改年份。
3. **跑过的回归都在正文或附录里。** 异质性切了几刀，表里就列几刀；第七节自动检查跑的备选也列。

这三条之外，**都按同刊标准放松**：不做 BH，不算有效样本量，不逐份核验，不因代理不完美而拒用。政策时间、文号凡没核实的，写"需核实"，**不编造**。

## 八、卡住了怎么办（自己决定，不要停下来等人）

| 情况 | 怎么办 |
|---|---|
| 地市在园幼儿数缺得太多（覆盖不到一半地市） | **降级到省级面板**（31 省 × 2010—2023，教育统计年鉴），处理定义为"全省或省内主要地区先行免费"；处理省份少（4—9 个）照用，同刊有先例；聚类到省，样本小就加报 wild bootstrap p 值 |
| 省级也拿不全 | **再降级到 CFPS 个体**：3—6 岁儿童是否入园 × 所在省是否免费 × 年份，个体 DID；同刊有用调查数据的先例 |
| 2025 年后轮只有一年 | 表 12 改成 2025 年**一年截面**：中央分担档次与 2025 年在园数变化（2024→2025）的回归，同刊有一年截面先例；数据未出就跳过表 12，一页纸写"未做：数据未发布" |
| 试点年份查不到 | 按最早公开报道年份，标"需核实"，继续；不逐个打电话、不人工逐份考证 |
| 某个变量拿不到 | 跳过，在一页纸上写一行"未做：原因"，继续 |
| 某个主 C 加控制后不显著 | 两列都报，正文用"无控制显著、加控制后方向一致"的同刊写法；不换 C、不换样本（第七节备选只跑一次） |
| 事件研究事前有一年显著 | 照报，正文写"事前系数大体不显著"，加省×年固定效应结果作补充 |
