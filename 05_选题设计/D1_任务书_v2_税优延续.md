## 一、主设定（已写死，不再改）

| 项目 | 设定 |
|---|---|
| 冲击 A | 2023 年税费优惠政策延续与优化（财政部、税务总局公告 2023 年第 12—19 号，以及第 7 号研发加计 100% 长期实施）。论文里统一叫"**2023 年税费优惠政策延续优化**"，不叫"纯期限冲击" |
| 处理强度 | **E3**：2020—2021 年"收到的税费返还"÷ 营业收入的均值（连续变量，标准化）。不用 2022 年，因为 2022 年第四季度研发加计扣除已临时提到 100%，被污染 |
| 政策后 | Post = 2023 年及以后 |
| 参照年 | 事件研究以 **2021 年**为基期 |
| 主样本 | A 股非金融、非 ST 上市公司，2018—2025 年 |
| 主模型 | `reghdfe C c.E3#c.Post 控制变量, absorb(企业 年份 行业×年份) vce(cluster 企业)` |
| 控制变量 | 规模、杠杆、ROA、上市年限、营收增长、第一大股东持股、两职合一，全部滞后一期 |
| **出口退税处理** | 主回归加"出口收入占比（2020—2021 均值）× Post"作控制；稳健性里剔除出口占比前 25% 的企业 |
| 主结果 C | 员工人数（对数）、研发强度、长期投资（购建长期资产现金 ÷ 总资产） |

**第一轮已知结果**（照抄 Agent 第一轮，供参考，以本轮重跑为准）：E3 × 员工 +0.017，p=0.002，事前检验 p=0.74；E3 × 研发（无控制）+0.0017，p=0.01；E3 × 长期投资 −0.0052，p<0.001。

**故事主线（据此排表）**：

> 税费优惠延续后，受益越多的企业**雇佣更多、研发更多，而固定资产投资相对减少**——企业把确定性带来的空间从"投资于物"转向"投资于人"。分析师上调盈利预期、年报语调更乐观，说明预期改善是渠道；现金流改善、有效税率下降说明"钱"也是渠道。

长期投资为负**不藏**，正面写成"投资结构转向"，在第五章第 1 节单独成一张表。

## 五、怎么写结果（同刊措辞，数字照表）

### 5.1 措辞模板

| 情况 | 写法 |
|---|---|
| p < 0.01 | "在 1% 水平上显著为正，表明……" |
| p < 0.1 | "在 10% 水平上显著，表明……"（**照写"显著"**，同刊惯例） |
| 方向对、不显著 | "系数为正但不显著，说明……的作用存在边界 / 仍有待进一步释放" |
| 方向相反 | 照实报；能在故事里解释就解释（如长期投资为负 = 投资结构转向），解释不了写"可能的原因是……" |
| 异质性某组显著、另一组不显著 | "**上述效应主要集中在××企业**"，并报组间差异检验 p 值 |
| 机制变量显著 | "这验证了预期改善 / 资金约束缓解渠道" |

### 5.2 不越的线（只有这三条）

1. **正文写的每个数字，都能在表里找到。**
2. **不改数据、不删样本去凑显著。** 样本筛选只按第一节写死的规则。
3. **跑过的回归都在正文或附录里。** 异质性切了几刀，表里就列几刀，不显著的组也列。

这三条之外，**都按同刊标准放松**：不做 BH，不算有效样本量，不逐份核验，不因代理不完美而拒用。
