# 选题设计协议（每个话题一份）

背景：我们写的是财政学冲击回归论文，对标《经济研究》《管理世界》《财政研究》《税务研究》等同刊质量（同刊常见：10%显著也写有效、指标代理较远、处理组小、检验放附录）。故事方向必须是"国家政策 A 让 C 变好"（正面）。A 只要差不多能找到数据、勉强对得上即可。
可参考：/home/user/FiscalDarkPath/02_批量检验/五词文献调研/数据/五词合并编码.csv（506 篇同刊编码，看别人用过的 A、C、数据），/home/user/FiscalDarkPath/02_批量检验/五词文献调研/新A调研/*.md，/home/user/FiscalDarkPath/02_批量检验/五词文献调研/全文编码/*.md。
可用 WebSearch 核实政策时间、文号、数据来源；查不到写"需核实"，不要编造。

输出（Markdown）：
1. **A 清单（≥8 个）**：每个写政策名、文号或发布机关、时间、处理变量怎么构造（分批/强度/暴露度）、数据来源（名称、层级、年份、获取方式）、可行度（高/中/低）。可以"强行凑"：比如同一政策换不同暴露度、相关配套政策、前后几轮政策。
2. **C 清单（≥8 个）**：每个写指标、口径、数据来源、年份、同刊先例（引编码表里的编号或文章）、跑出结果的可能性（高/中/低，凭经验判断理由）。
3. **A×C 组合推荐（≥8 个，排序）**：每个写一句话故事、样本（层级、年份）、模型（DID 类型）、预期方向、为什么容易跑出来。
4. **机制链（每个推荐组合至少 1 条，前 3 个组合给 2 条）**：写成 A → B → D → E → C 的长链，每一环写可测指标与数据来源；标明哪几环做"A→中间变量"回归、哪环做调节或异质性、哪环可以做"中间变量→C"。链条要逻辑顺、能讲故事。
5. **异质性与拓展**：3—5 个同刊常见的分组维度和延伸（如"财政压力高低""东中西部""国企民企""质量/效率"）。
6. **风险与后备**：每个推荐组合的主要风险和备选指标。
