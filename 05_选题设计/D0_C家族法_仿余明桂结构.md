# C 家族法：仿余明桂（2026）的结构改造五个选题

> 样板：余明桂等（2026）《数字基础设施建设、公共算力供给与 AI 创新》，经济研究。原文 `papers/02_AI与学科交叉_第二批/`，大白话拆解 `01_单篇拆解/余明桂等2026_公共智算中心与AI创新_大白话拆解.md`。

## 一、样板的骨架（大白话）

> B 很重要但很贵 → 国家搞了 A → A 让主 C 变多（尤其在某些企业）→ A 还促进了 D 和 E（机制）→ 民企、小企业更明显（异质性）→ 进一步：C 的质量也高了、还扩散到别的领域、连 TFP 都提高了。

拆开看，它的"AI 创新"不是一个 C，而是**一个 C 家族**：

| 位置 | 余明桂的做法 | 我们照着排 |
|---|---|---|
| 主 C（正文第五节） | AI 专利数量 | 最直接的"数量"指标 |
| 机制 D、E（第六节） | 研发投入、AI 人才配置 | 两条中介 |
| 异质性 | 民营、小规模；AI 企业、潜在算力需求强 | 3—4 个分组 |
| 进一步（第七节） | AI 质量、知识扩散、TFP | 质量 C、溢出 C、效率 C |

## 二、我们怎么用：设计"C 家族"，事先写好"全跑清单"

做法：
1. 每个选题先定一个"大 C"，拆成 4 层：**数量 → 质量 → 溢出 → 效率**。
2. 列出 A × 每层 C × 每条机制 × 每个分组的全部回归，**跑数前写定**，作为"全跑清单"。
3. 正文按样板顺序排：主 C → 机制 → 异质性 → 进一步。

**和"挑显著的报"的区别（这条按 `CLAUDE.md` 的底线办）：**
- 全跑清单里的回归**全部报告**。主结果和最强的放正文；其余放"进一步分析"或附录，不显著的也列出，写成"作用边界"或"该维度证据较弱"。
- 正文放哪几个，在跑数前按"离 A 最近的 C"确定，**不按跑出来的显著性挑**。
- 版面上看起来和样板一样，主结果在前，次要结果在后；区别在于我们不把不利结果藏起来。审稿人越来越常要求附录全量，这样做也更安全。

## 三、五个选题的 C 家族

### D1 税优延续 → 企业"高质量发展"

- **B（瓶颈）**：政策不确定性。优惠年年到期，企业不敢做长期决策。
- **A**：2023 年 8 月公告第 12—19 号集中延续；第 7 号研发加计扣除 100% 制度化。
- **主 C（数量）**：研发投入强度。
- **机制 D**：管理层预期改善（年报前瞻语调、分析师预测上调）。
- **机制 E**：融资约束缓解（现金持有、长期负债占比）。
- **进一步**：
  - 质量：发明专利占比、专利被引；
  - 溢出：供应链上下游企业的研发；
  - 效率：TFP、长期投资占比。
- **异质性**：民营与国有；小微与大中型；政策依赖度高与低；数字化程度高与低。
- **大白话**：企业怕政策说变就变 → 国家一次把优惠延到 2027 年 → 企业敢投研发了，尤其是小微民企 → 因为老板预期变好、钱也更宽裕 → 专利质量更高，还带动了上下游，TFP 也涨了。

### D2 营改增与五五分成 → 地方"投资于人"

- **B**：地方自主财力不足。
- **A**：2016 年全面营改增，加上增值税五五分成（机械增收强度）。
- **主 C**：教育、卫生健康、社保就业支出占比。
- **机制 D**：财政自给率提高。
- **机制 E**："三保"压力缓解、土地出让依赖下降。
- **进一步**：
  - 质量：生均教育经费、每千人医生床位；
  - 溢出：周边城市民生支出；
  - 效率：民生支出效率、人口流入。
- **异质性**：中西部与东部；财政压力高与低；省直管县与否。
- **大白话**：地方没钱办民生 → 国家把增值税五五分成 → 分成补偿多的城市民生支出涨得快 → 因为自给率高了、不再光靠卖地 → 学校医院也更好了，还留住了人。

### D3 清欠 → 民营经济信心

- **B**：政府拖欠账款，民企现金流紧张。
- **A**：2018—2019 年清欠专项行动、2020 年支付条例、2024—2025 年新一轮清欠。
- **主 C**：回款周期、应收账款占比下降。
- **机制 D**：经营现金流改善。
- **机制 E**：融资约束缓解。
- **进一步**：
  - 预期：年报语调；
  - 投资：固定资产与研发；
  - 溢出：给下游供应商的付款也加快（商业信用传递）；
  - 效率：TFP。
- **异质性**：政府客户占比高与低；中小与大型；地方财政压力高与低。
- **大白话**：政府欠民企钱 → 国家搞清欠 → 被欠多的企业回款快了 → 现金流好了、贷款容易了 → 信心回来了，敢投资了，还把钱付给了自己的供应商。

### D4 学前免费 → 学前普及（投资于人 × 生育支持）

- **B**：学前教育费用高，家庭负担重。
- **A**：地方先行免费；2025 年学前一年免保教费的中央分档；学前教育三年行动计划。
- **主 C**：入园率、在园幼儿数。
- **机制 D**：家庭教育支出下降。
- **机制 E**：普惠园和公办园供给增加。
- **进一步**：
  - 质量：幼师数量与学历；
  - 溢出：母亲就业；
  - 远期：儿童认知、生育意愿。
- **异质性**：农村与城市；财政压力；中央分档档次。
- **大白话**：上幼儿园贵 → 国家和地方免费 → 入园的孩子多了 → 因为家里省钱了、普惠园多了 → 老师更好了，妈妈能去上班了，孩子更聪明了，家长也更敢生了。

### D5 基础养老金与新农保 → 老有所养

- **B**：农村老人缺少稳定收入。
- **A**：新农保分县试点；2014、2018、2024、2025 年基础养老金提标，加上各省加发强度。
- **主 C**：老人收入与贫困。
- **机制 D**：流动性约束缓解。
- **机制 E**：子女负担减轻（代际转移下降，照实写）。
- **进一步**：
  - 消费：消费水平和结构；
  - 健康：抑郁、自评健康、该就医未就医；
  - 福祉：主观幸福感。
- **异质性**：高龄与低龄；独居与否；中西部与东部（中央补助比例不同）。
- **大白话**：农村老人没钱 → 国家发养老金并逐年加码 → 老人收入高了、穷的少了 → 手头宽裕了、少向子女伸手 → 吃得好了、敢看病了、心情好了。
