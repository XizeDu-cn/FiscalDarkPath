## 〇、原来的 C 还能不能写？——能，而且没到放弃的时候

原题 C 是"**企业预期**"和"**投资于人**"（研发、长期投资、雇佣）。对照前两轮：

| 原 C | 前两轮证据 | 判断 |
|---|---|---|
| 企业预期 | 年报讨论章节整体语调为正，p≈0.044；第一轮 E2 与分析师 EPS 上修正相关（q≈0.02） | **已有支撑**，只是测法太少 |
| 投资于人：就业规模 | 员工 +0.014，p=0.014，事前 p=0.77 | **已有支撑** |
| 投资于人：效率 | LP 法 TFP +0.043，p=0.0004 | **强支撑**（人力投入转化为生产率） |
| 投资于人：研发与人员结构 | 研发不显著；研发人员、本科占比为负 | 只用了最窄的测法，还没试薪酬、培训、股权激励、招聘学历等 |
| 长期投资 | 毛资本开支为负 | 正好对应"从投资于物转向投资于人"，可以保留为投资结构的证据 |

**结论**：原题《税收优惠延续政策与企业预期重塑》加"投资于人"的主线**仍然站得住**。问题不是 C 选错了，而是**测得太窄**。本轮先扩 C 的测法，再决定标题落在哪个词上。

## 一、为什么跑了 874 个规格，却好像只剩一个故事

问题不在组合数，而在**组合的方向**：

1. **深度有余，广度不足。** 874 个规格里大部分是同一组 C（员工、研发、资本开支）的稳健性变体：换控制、换样本、换出口口径。真正不同的 C 不到 20 个。
2. **只押一个暴露度。** E3（税费返还 ÷ 营收）一个变量扛全部；E1、E2 退到稳健性；A3（研发加计历轮）、A5（留抵退税扩围）、A4（先进制造业加计抵减）这些设计稿里的其他 A **从未作为独立主线跑过**。
3. **样本不对口。** 2023 年延续主要惠及小微和个体户，上市公司里几乎没有小微。信号弱，首先是样本问题。
4. **C 只来自年度财报。** 政策后只有 2024、2025 两个年度点；没有月度招聘、没有工商注册、没有更多文本指标。
5. **没造综合指标。** 同刊常用的数字化转型指数、新质生产力指数、企业韧性、ESG 员工维度，一个都没构造。
6. **机制和异质性被当成"证伪"来跑。** 切的刀少，跑不显著就写"无稳定差异"。

本轮逐条对着改。

## 二、标题怎么起（同刊审美）

从编码过的 212 篇里看四大刊的标题，规律有三条：

- **"××的××效应"或"A、B 与 C"并列**：《社保缴费基数限额下调的稳就业与促投资效应研究》（管理世界）、《企业社保减负的就业结构优化与居民消费提振效应》（管理世界）、《税收激励、人力资本投资与企业劳动生产率》（数量经济技术经济研究）、《促就业与稳增长：养老保险缴费率的视角》（经济研究）。

## 六、机制和异质性的写法（这次按"讲故事"跑）

- **异质性至少切 8 刀**：产权、规模、融资约束、行业技术密集度、劳动密集度、地区、市场化程度、地方财政压力、高管背景（选做）。每刀都列在表里，显著的那组写"**效应在××企业中更为突出**"。
- **机制两条路都跑满**："钱"（现金流、有效税率、SA、KZ、WW 三种融资约束指标、银行借款）；"预期"（第 4.1 节全部指标）。
- 每条机制配一句同刊式结论："这表明，税费优惠延续通过稳定企业预期，促进了企业人力资本投资"。
