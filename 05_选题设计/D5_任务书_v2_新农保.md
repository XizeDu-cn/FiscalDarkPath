## 一、主设定（起点设定，可按通用规则 v2.1 调整）

| 项目 | 设定 |
|---|---|
| 冲击 A | 城乡居民基础养老金提标（主 A4+A5）：2014 年 7 月全国最低标准 55→70 元（人社部发〔2015〕5 号，**需核实**）、2018 年起 88 元（人社部发〔2018〕21 号，**需核实**），叠加各省自行加发。论文里统一叫"**基础养老金提标**"。前轮 A1 新农保试点（国发〔2009〕32 号）只放附录 |
| 处理强度 | **主强度 S**：省份 p 在年份 t 的实际基础养老金月标准（全国最低 + 省级加发）× 12 ÷ 2011 年该省农村居民人均消费支出（替代率，基期固定，不随年变）。以 2011 年为零点，用"相对 2011 的替代率增量 ΔS"，标准化 |
| 受影响人群 | Old = 调查当年年满 60 岁（农业户口、未领职工养老金）；45—59 岁作对照 |
| 主模型 | `reghdfe C c.ΔS#i.Old Old 控制变量, absorb(个体 县×波次) vce(cluster 县)` |
| 事件研究 | Old × 波次（2011/2013/2015/2018/2020），**基期 2013**（2014 年 7 月提标之前最后一波）；同时报 Old × ΔS × 波次的强度版 |
| 主样本 | CHARLS 2011、2013、2015、2018、2020 五波，农村户籍、45 岁及以上个体；剔除领取职工养老金/机关事业退休金者。只按这条筛，不再调 |
| 控制变量 | 年龄（二次项）、性别、婚姻、受教育年限、家庭规模、存活子女数、慢性病数（基期值×波次，避免坏控制）|
| 主结果 C | **C1 贫困**（家庭人均收入低于当年国家农村贫困线，2010 年不变价 2,300 元，按年调整）和 **C1 人均收入（对数）**——离 A 最近、CHARLS 现成可构造 |
| 第一阶段 B | 个人养老金收入（元/年，对数+1）、是否领取城乡居民养老金 |

**故事主线（据此排表）**：

> 国家一次次给农村老人"加码"发养老金。加码越多的省，60 岁以上农村老人**养老金真到手了、贫困率下降、收入上升**；手头宽裕后借钱少了、消费上去了、该看病时看得起了（钱的路径）；对"将来靠谁"更有底，抑郁下降、满意度上升，不用再向子女伸手、高龄老人少干重活（人的路径）。效果集中在高龄、独居、中西部、财力弱的县——正是最需要兜底的人。父母不拖累，子女更敢外出，孙辈教育投入增加："一代养老，三代受益"。

子女转移下降、劳动供给下降**不藏**，正面写成"减轻子女负担""减少被迫劳动"，各占机制二表里一列。

## 五、怎么写结果（同刊措辞，数字照表）

### 5.1 措辞模板

| 情况 | 写法 |
|---|---|
| p < 0.01 | "在 1% 水平上显著为负，表明基础养老金提标显著降低了农村老人贫困发生率……" |
| p < 0.1 | "在 10% 水平上显著，表明……"（**照写"显著"**，同刊惯例） |
| 方向对、不显著 | "系数符号符合预期但不显著，说明……的作用存在边界 / 仍有待进一步释放" |
| 方向相反 | 照实报；能在故事里解释就解释（子女转移下降 = 减轻子女负担；劳动下降 = 减少被迫劳动），解释不了写"可能的原因是……" |
| 异质性某组显著、另一组不显著 | "**上述效应主要集中在高龄 / 独居 / 中西部老人**"，并报组间差异检验 p 值 |
| 机制变量显著 | "这验证了流动性约束缓解 / 养老预期稳定渠道" |

### 5.2 不越的线（只有这三条）

1. **正文写的每个数字，都能在表里找到。**
2. **不改数据、不删样本去凑显著。** 样本筛选只按第一节写死的规则。
3. **跑过的回归都在正文或附录里。** 异质性切了几刀，表里就列几刀，不显著的组也列；第 2 天备选跑了，两版都报。

这三条之外，**都按同刊标准放松**：不做 BH，不算有效样本量，不逐份核验，不因代理不完美而拒用。政策文号凡标"需核实"的，正文照样标"需核实"，不自己补文号。
