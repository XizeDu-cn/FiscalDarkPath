## 一、主设定（起点设定，可按通用规则 v2.1 调整）

| 项目 | 设定 |
|---|---|
| 冲击 A | **A1 增值税央地分成五五调整**：国务院国发〔2016〕26 号《全面推开营改增试点后调整中央与地方增值税收入划分过渡方案》，2016-05-01 起，增值税央地分成 75:25 → 50:50，以 2014 年为基数核定返还/上解。论文里统一叫"**营改增全面推开后的增值税五五分成改革**" |
| 处理强度 | **Mech（机械增收强度）**= 0.25 × 2015 年本地国内增值税收入 ÷ 2015 年一般公共预算收入（连续变量，标准化）。只用 2015 年（改革前一年），不用 2016 年及以后 |
| 政策后 | Post = 2016 年及以后（2016 年 5 月实施，2016 年算处理年；稳健性里剔除 2016 年） |
| 参照年 | 事件研究以 **2015 年**为基期 |
| 主样本 | 地级及以上城市（约 280 个），2010—2021 年；直辖市保留，稳健性里剔除 |
| 主模型 | `reghdfe C c.Mech#c.Post 控制变量, absorb(城市 年份) vce(cluster 城市)` |
| 控制变量 | ln 人均 GDP、ln 人口密度、第二产业增加值占比、城镇化率（或非农人口占比）、ln 人均转移支付（有就加，没有就不加），全部滞后一期 |
| **同期混杂处理** | 稳健性里加省×年固定效应（吸收国发〔2016〕49 号事权改革等省级同期政策）；再控制"2015 年第二产业占比 × Post" |
| **主结果 C** | **C2 人均教育支出（对数）**——城市统计年鉴直接有、样本最全、离"多分到钱"最近 |
| 同表第二结果 | C1 民生支出占比 =（教育 + 卫生健康 + 社会保障和就业）÷ 一般公共预算支出（地市决算可得的城市子样本） |
| 分项 | C5 社保就业支出占比、C6 卫生健康支出占比（2018 年科目改名，统一口径为"医疗卫生"） |

**事先写好的备选（只在第七节第 2 天检查触发时用）**：

| 备选 | 设定 | 为什么选它 |
|---|---|---|
| 备选强度 **Ind** | 2015 年第二产业增加值占比 × Post（标准化） | 城市统计年鉴现成，不依赖分税种增值税；增值税税基主要在工业，同刊有"产业结构代理税基"的先例（正文写"以产业结构刻画增值税税基"）|
| 备选 C | C1 民生支出占比 | 设计稿第 3 节排名第 1 的组合 |

**故事主线（据此排表）**：

> 营改增全面推开后增值税五五分成，增值税依赖度越高的城市"机械地"多分到一块自主财力。这些城市的**教育、卫生、社保支出上升更快**——地方把新增财力投向了"人"。机制一是"钱"：财政自给率上升、对转移支付依赖下降、"三保"压力缓解；机制二是"激励"：留成从四分之一变一半，地方更愿意养税源而不是卖地，土地出让依赖和基建支出占比下降，钱从"物"转向"人"。财政越紧、越在中西部的城市效果越大（"雪中送炭"）。进一步看，医生、床位、教师多了，人口愿意流进来。

## 五、怎么写结果（同刊措辞，数字照表）

### 5.1 措辞模板

| 情况 | 写法 |
|---|---|
| p < 0.01 | "在 1% 水平上显著为正，表明……" |
| p < 0.1 | "在 10% 水平上显著，表明……"（**照写"显著"**，同刊惯例） |
| 方向对、不显著 | "系数为正但不显著，说明……的作用存在边界 / 仍有待进一步释放" |
| 方向相反 | 照实报；能在故事里解释就解释（如基建占比下降 = 从"投资于物"转向"投资于人"），解释不了写"可能的原因是……" |
| 异质性某组显著、另一组不显著 | "**上述效应主要集中在××城市**"，并报组间差异检验 p 值 |
| 机制变量显著 | "这验证了财力补偿 / 税源激励渠道" |
| 用了备选强度或备选 C | "以产业结构刻画增值税税基"/"以民生支出占比衡量"，两套结果都报，正文写"结论基本一致"或"主要体现在……" |

### 5.2 不越的线（只有这三条）

1. **正文写的每个数字，都能在表里找到。**
2. **不改数据、不删样本去凑显著。** 样本筛选只按第一节写死的规则。
3. **跑过的回归都在正文或附录里。** 异质性切了几刀，表里就列几刀；备选强度、备选 C 跑了就报，不显著的也列。

这三条之外，**都按同刊标准放松**：不做 BH，不算有效样本量，不逐份核验，不因代理不完美而拒用。政策文号、日期凡本任务书或设计稿标"需核实"的，写进初稿时照样标"需核实"。
