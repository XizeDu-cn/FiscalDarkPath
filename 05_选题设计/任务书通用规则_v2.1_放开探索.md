# 任务书通用规则 v2.1：放开探索（D1—D5 共用，优先于各任务书）

> 各 `D*_任务书_v2_*.md` 里凡是"写死、不再改""回归总数上限""超过 100 个就停""只允许一次备选""不加新模块、新 C、新强度"等条款，**一律按本文件放宽**。两者冲突时以本文件为准。
> 质量标准仍是 `CLAUDE.md`：对标同刊。

## 一、为什么放开

v1 的毛病是"审计"，不是"跑得多"。审计是指一遍遍论证同一个结果对不对；探索是指多试几种 A、C、指标、样本，找出能讲的故事。**同刊作者都在探索**，只是不写出来：

- 实际出生数不显著，就用理想子女数、生育意愿（同刊先例）。
- 财政压力没有好指标，就用限购哑变量代理。
- 处理组只有 4—9 个省也照发。
- 主结果只在 10% 水平显著，也写"显著"。

所以：**任务书里的主设定是起点，不是笼子。** Agent 是研究者，不是流水线。

## 二、可以自由做的事

1. **换指标、造指标。** 某个 C 不显著，可以换同一概念的其他测法，或自己构造：比值、增长率、虚拟变量、综合指数（熵值法、主成分）、文本词频、行业或地区层面汇总。同刊里能找到类似先例就够了。
2. **换代理的"远近"。** 概念和实测差一截可以接受，比如出生数换成生育意愿，"投资于人"换成研发人员占比、薪酬，"预期"换成语调、分析师预测。
3. **换强度和处理组。** 连续强度、二元分组、三分位、前后 25%、名单 DID 都可以试。
4. **换样本和窗口。** 子样本、延长或缩短窗口、剔除特殊年份或行业、年度改季度都可以。前提是有一句说得通的理由（例如剔除疫情年、剔除金融业），并且写进正文或附录。
5. **加机制、加异质性、加进一步分析。** 看到能延伸的故事就跑，不用请示。异质性能切多少刀就切多少刀。
6. **换模型。** 加控制和不加控制、换固定效应、换聚类层级、PSM-DID、熵平衡、交错 DID 估计量都可以试。
7. **回归数量不设上限。** 尽可能多跑，多出结果。

## 三、关键地方的声明（只有这几条不能松）

1. **数字和表一致。** 正文写的每个系数、p 值，都能在输出表里找到。
2. **不改数据。** 不手改观测值，不编造数据。删样本、缩尾必须用一条写得出来的规则，对所有回归一视同仁。
3. **探索日志全记。** 每跑一个回归，自动往 `探索日志.csv` 追加一行：编号、A、强度、C（含构造方式）、样本、模型、系数、标准误、p 值、N、是否进正文。**这是唯一的"审计"，由代码自动生成，不写长文。**
4. **正文挑能讲的，附录列全部。** 正文可以只放讲得通的那一版，这是同刊惯例；但附录要附一张"替代设定汇总表"，把同一 C 的其他测法、其他样本的结果列出来，让人能看到全貌。
5. **自造指标写清构造。** 每个自造指标在正文或附录写一句定义和理由，不藏构造方式。
6. **不说反话。** 正文结论不能和附录里更主要的设定直接矛盾却不提。冲突时写"在××设定下更为明显"或"存在边界"。
7. **政策事实**：文号、日期没核实的标"需核实"。

## 四、仍然不要做的事（这些是浪费，不是"严谨"）

- BH 多重检验校正、有效样本量计算
- 人工逐份核验年报、资格名单
- 来源登记表、审计 JSON、方法论辩护长文
- 因为代理"不够纯"就拒绝用同刊常用的变量（TFP、SA 指数、语调等）

## 五、交付物（在各任务书第六节基础上调整）

- 各任务书第六节列的代码、表、图、结果章节初稿、一页纸照交。
- 新增 `探索日志.csv`（自动生成）。
- 新增 `附录_替代设定汇总表.rtf`。
- 一页纸增加一栏"**最好讲的故事**"：Agent 根据全部探索结果，推荐正文用哪条线，3—5 行说明理由。
- 如果探索中发现比任务书主设定更好讲的组合，**直接按新组合出正文表**，原主设定放附录，在一页纸里说明。

## 六、时间

仍以 5 天左右交出正文表为目标。探索边跑边记，不必等全部跑完才出表；第 3 天先交一版正文表和一页纸，之后继续探索、更新。
