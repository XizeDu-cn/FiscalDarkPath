# D2 营改增全面推开与地方"投资于人"——基于增值税分享比例调整的证据

> 按《设计协议》出稿。文号/日期凡标"需核实"的，未经本轮联网核对，投稿前须逐条查原文。未标注的为常识性政策事实，也建议在终稿前对一次财政部/国务院官网原文。
> 同刊先例编号取自 `五词合并编码.csv`（TR=投资于人，FC=房地产批，SB=社保，YQ=预期管理）。

**总体故事**：营业税原为地方主体税种。营改增后，原营业税并入增值税，国发〔2016〕26 号把增值税央地分成从 75:25 改为 50:50，并以 2014 年为基数核定返还/上解。原营业税税基越大的地区，"改革前后财力缺口"越大，但"五五分成"也让增值税税基越厚的地区多分了一块，且分成后地方能从本地增值税增长中多拿钱。正面故事是：**分成补偿越多 → 地方可支配自主财力越多、越稳定 → 财政压力和"保运转"挤出下降 → 支出结构向教育、卫生、社保这些"投资于人"的方向倾斜**。

**核心识别（推荐的主设定）**：连续强度 DID。处理强度 = 2015 年（改革前一年）本地国内增值税收入占地方一般公共预算收入的比重，或者"分成调整的机械增收"=（50%−25%）× 2015 年本地国内增值税 ÷ 2015 年一般公共预算收入。乘以 Post2016。地级市面板 2010—2021 年。

## 5. 异质性与拓展（同刊常见）

1. **财政压力高低**：2015 年财政自给率或"三保"占比的中位数分组，预期压力高的地区效应更大（"雪中送炭"）。
2. **东中西部 / 转移支付依赖度**：中西部原本更依赖转移支付，自主财力增量的边际效应更大；也可以按 A10 的央地共同事权分档（第一档至第五档）做调节。
3. **人口流入或流出**：流入城市的公共服务需求压力大，分成补偿更多转向教育（随迁子女）；可以接 TR-030 的叙事。
4. **债务压力 / 土地财政依赖**：土地财政依赖高的城市"投资于物"的惯性更强，效应更弱，用来证明结构替代机制。
5. **拓展（质量与效率）**：C8 支出效率、C9 均等化指数、城乡差距（城乡教育资源差距）；再延伸到人力资本结果（高中毛入学率、人均预期寿命，需核实地市数据可得性）。

## 8. 机制网

```
  A1 增值税五五分成(2016,主) ──┐
  A3 全面推开·行业扩围(2016) ──┤
  A7 2014基数返还(兜底) ───────┼──→ B 地方自主财力↑（机械增收强度）
  A5 分成"稳定不变"(2019) ─────┤        │
  A8 省以下分成下沉(各省) ─────┘        │
                                        ├─【钱】D1 财政自给率↑、转移支付依赖↓ ──┐
                                        ├─【钱】D2 "三保"压力↓、收入波动↓ ─────┤
                                        ├─【激励】E1 边际留成25%→50%：税源培育 ┤
                                        │        → 制造业/服务业税基↑ → 再分成 ─┤
                                        └─【激励/预期】E2 土地出让依赖↓、基建占比↓┤
                                                  （"投资于物"→"投资于人"）      │
   ┌────────────────────────────────────────────────────────────────────────┘
   ▼
 C 层1 直接：教育/卫生/社保支出占比、人均（C1 C2 C5 C6）
 C 层2 质量效果：专任教师、生均经费、每千人医生床位、支出效率、均等化指数（C3 C4 C8 C9）
 C 层3 远期溢出：常住人口流入、人力资本（高中入学等，需核实）、周边城市带动（空间溢出）
```

**为什么互相支撑**：
1. 钱路径（D1、D2）解释"有钱才能投"；激励路径（E1、E2）解释"为什么投给人而不是物"。只靠钱路径会被问"多出的钱为什么不去修路"，E2 的基建占比下降正好回答；只靠激励会被问"激励从哪来"，B 的机械增收是源头。
2. 多个 A 指向同一个 B：A1 给增量，A7 保存量，A5 稳预期，A8 把钱下沉到县。若 A1 被质疑混杂同期事权改革（国发〔2016〕49 号），A8 的分省交错时间提供另一套识别。
3. C 三层递进：层 1 证明钱花了，层 2 证明花出效果，层 3 证明人"用脚投票"。异质性（财政压力高、中西部、土地依赖低）与机制方向一致，形成交叉验证。

## 10. 全文章节结构（大白话）

1. **引言**：十五五讲"投资于人"、讲增加地方自主财力（表述需核实原文）；地方财力紧，民生欠账多。2016 年营改增叠加五五分成，相当于中央和地方重新分了一次钱。我们发现，多分到钱的城市，教育、卫生、社保花得更多，而且花出了效果。
2. **政策背景与典型事实**：讲营改增三步走（2012 试点、2013 扩行业、2016 全面推开）和分成从 75:25 到 50:50。画图：各地增值税依赖度差异很大；高依赖城市 2016 年后民生支出占比走势明显上翘。
3. **理论分析与假说**：画第 8 节的机制网。假说 1：分成补偿让民生支出上升；假说 2：靠"有钱"（自给率、三保压力）；假说 3：靠"想投"（税源激励、少卖地少修路）；假说 4：财政越紧的地方效果越大。
4. **研究设计**：地级市 2010—2021，处理强度 = 0.25×2015 年增值税/一般预算收入，乘 2016 年后哑变量；城市、年份固定效应。
5. **基准回归与稳健性（G1—G3）**：强度每高 1 个标准差，民生支出占比多涨若干个百分点（以回归表为准）。事件研究看平行趋势；换强度口径（扣返还净增收、A3 行业暴露）、排除同期事权改革与"三保"、剔除直辖市，结论不变。
6. **机制一：钱（G4、G5）**：多分的钱让自给率上去、对上级转移支付的依赖下来；原来"三保"吃紧的地方，腾出手来投民生。
7. **机制二：激励（G6、G7）**：留成从四分之一变一半，地方更愿意养税源而不是卖地；土地出让依赖和修路建城的支出占比下降，钱从"物"转向"人"。
8. **异质性（G8—G10）**：财政压力大的、中西部的、对卖地依赖小的城市效果更大，"雪中送炭"。
9. **进一步分析一：投出了效果（G11—G13）**：医生和床位多了，教师多了，民生支出效率和公共服务均等化程度提高。
10. **进一步分析二：远期与溢出（G14、G15）**：人口愿意流进来，周边城市也被带动。
11. **进一步分析三：系列改革（G16、G17）**：2019 年明确分成长期不变后效果延续；省里把分成往下放，县级民生支出也涨了。
12. **结论与政策建议**：见第 11 节。

## 11. 政策建议（大白话）

1. **稳住并适度提高地方共享税分成**（对应基准、进一步三）：分成给得稳、给得够，地方才敢做教育、医疗这种长期投入。
2. **补齐地方自主财力、给"三保"兜底**（对应机制一）：钱是第一道门槛，财力紧的地方多分一块效果最大。
3. **用分成激励引导地方少卖地、多养税源**（对应机制二）：让地方从"投资于物"转向"投资于人"有利可图。
4. **向中西部和财政困难地区倾斜，并推动省以下财力下沉到县**（对应异质性、进一步三）。
5. **把民生支出的考核从"花了多少"转向"花出什么效果"**（对应进一步一、二）：看医生床位、教师、均等化和人口流入。
