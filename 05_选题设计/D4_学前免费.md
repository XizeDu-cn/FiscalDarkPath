## 3. A×C 组合推荐（排序）

1. **A2×C1/C2（地方先行免费 → 入园率）**：在地方免费试点地区，入园率和大班在园数上升。样本为县或地市，2012–2023；交错 DID 加事件研究。预期为正。容易跑出的原因：处理对象和结果之间几乎没有中间环节，同时有多个批次。
2. **A3×C1+C9（三期行动计划强度 → 入园率 → 儿童认知）**：基期缺口大的县，入园率追赶更快，儿童认知更高。县级 2008–2020 加 CFPS 2010–2020；Bartik 连续 DID。预期为正。容易跑出的原因：有先例 TR-046，缺口均值回归本身也会推高系数，这一点必须用安慰剂检验排除。
3. **A1×C2/C6（2025 年中央分档 → 在园数与家庭支出）**：中央分担比例高的省份，地方负担轻、落实快，在园数降幅更小。省级 2019–2026；分档连续 DID。预期为正。风险在于只有 1–2 期，宜作为"前瞻/政策评估"短文。
4. **A2×C7（免费 → 母亲就业）**：CFPS 中有 3–6 岁子女的母亲，2014–2022；个体 DID 或三重差分（有无适龄子女）。预期为正。适龄子女提供第三重差分，能增加识别力度。
5. **A4×C3/C5（中央学前资金 → 普惠园占比/幼师学历）**：省级 2011–2023，连续 DID，以公式因素作 IV。预期为正。
6. **A8×C3（"80/50"目标缺口 → 公办/普惠扩张）**：省、县级 2014–2022，强度 DID。预期为正，因为政策目标就是这个指标。
7. **A5×C4（生均补助 → 民办普惠园存续）**：县或企业注册数据，2015–2023，交错 DID。预期补助降低民办园退出，正面口径写"普惠转型"。
8. **A2/A3×C8（学前免费 → 生育意愿/出生率）**：县级出生率或 CFPS 理想子女数；DID。预期为正但较弱。卖点大，结果最不稳。
9. **A7×C9（幼儿资助 → 困难家庭儿童认知）**：CFPS 低收入分组，DID。

## 4. 机制链

**组合 1（A2×C1）**
- 链 1：免费 → 家庭面对的保教费价格下降（"A→B"：用 CFPS/CHFS 中的学前教育支出验证）→ 边际家庭（农村、低收入）入园决策改变（异质性：收入、户籍分组）→ 大班在园数上升 → 入园率上升（C）。A→B 回归、B 做异质性。
- 链 2：免费 → 地方学前财政投入增加（教育经费统计，A→中间变量）→ 公办/普惠学位扩张（幼儿园数、班额）→ 供给约束放松（调节：基期学位缺口）→ 入园率（中间变量→C 可做）。

**组合 2（A3×C1+C9）**
- 链 1：行动计划 → 中央专项资金到县（财政部分配表）→ 新建、改扩建园所数（A→D 回归）→ 3 公里内可及性（百度 POI，参考 TR-016）→ 入园率 → 认知（C9 用 CFPS 测验，中间变量→C）。
- 链 2：行动计划 → 幼师编制与培训（专任教师、专科率，A→中间变量）→ 师幼比改善 → 保教质量 → 儿童认知；以基期师资紧缺做调节。

**组合 3（A1×C2/C6）**
- 链 1：中央分担比例 → 地方净支出负担下降（预算数据，A→B）→ 落实时滞与覆盖完整度（调节：地方财政压力）→ 大班留园率 → 在园数。
- 链 2：免保教费 → 家庭学前支出下降（CFPS 2024 或 CHFS 后续）→ 释放的预算转向营养/兴趣班（家庭支出结构，中间变量→C）→ 家庭教育负担率下降。

**组合 4（A2×C7）**：免费 → 入园概率上升（个体层面）→ 母亲照料时间下降（CFPS 时间利用）→ 劳动参与与工时上升；以有无祖辈同住作调节。

**组合 5（A4×C3/C5）**：转移支付 → 生均公用经费上升 → 普惠园认定数 → 普惠占比；再加一环"幼师工资→专科率"。

**组合 6（A8×C3）**：目标缺口 → 考核压力（政府工作报告词频）→ 公办园扩建 → 公办占比。

**组合 7（A5×C4）**：生均补助 → 民办园收支缺口缩小 → 转为普惠的比例 → 存续率。

**组合 8（A×C8）**：免费 → 养育成本预期下降 → 理想子女数/二孩生育；以家庭收入、城乡分组做异质性。

**组合 9（A7×C9）**：资助 → 困难儿童入园 → 认知差距缩小。

## 5. 异质性与拓展
- 财政压力高低（自给率）：中央分档的核心卖点，财政越弱的地区，中央分担越重要。
- 东中西部/中央分档档次；城乡（农村/城区）。
- 公办与民办结构：基期民办占比高的地区是否出现挤出。
- 质量和数量：入园率对应数量，师资学历和班额对应质量。
- 拓展：代际与性别平等（母亲就业）、人口发展（生育），对接"投资于人"叙事（TR 系列）。

## 7. 扩充依据：扩 C 为主，辅以扩 A

本话题的处理变量里，单独看 A1（2025 年全国免费）事后期数太少，A2（地方先行）识别好但样本零散，所以**主处理用 A2，把 A1、A3 当作"前轮/后轮"扩 A**；结果端则从"入园"扩到"质量""家庭""远期"，以**扩 C 为主**。同刊做法：
- **高跃光（管理世界 2023）**：进一步分析把 C 外延到个体长期教育水平。对应本文把 C 从入园率延伸到儿童认知、远期生育。
- **吴子硕（财贸经济 2026）**：全文 9 节，计量结果、机制、异质性、进一步分开写，进一步分析多节。对应本文 3 节进一步分析。
- **曾益（财政研究 2025）**：两轮政策（2018 中央调剂 + 2022 全国统筹）同文评估。对应本文"地方先行（前轮）+ 2025 全国免费（后轮）"。
- **万晓莉（财贸经济 2023）**：两节机制分别走两条渠道。对应本文"钱"路径（家庭成本、财政投入）与"人/激励"路径（普惠供给、母亲时间）两节机制。
- **曾利飞（金融研究 2025）**：拓展中用家庭照护（亲情照护）做调节。对应本文用祖辈同住调节母亲就业效应。

## 8. 机制网

```
 前轮 A3 三期行动计划（2011—2020，资金+建园）──┐
 主   A2 地方先行免费（交错，县/地市）────────────┼─→ B 家庭学前成本↓ + 地方学前财力约束放松
 后轮 A1 2025 学前一年免保教费（中央 80/60/50 分档）┤        │
 配套 A4 中央学前资金、A5 普惠园生均补助 ───────────┘        │
                                                              ├─"钱"路径 D1：家庭保教费支出↓、学前财政投入占比↑
                                                              ├─"人/激励"路径 D2：普惠/公办学位↑、幼师编制与学历↑（供给侧）
                                                              └─"人/时间"路径 D3：入园概率↑ → 母亲照料时间↓
 C 层级：
   直接     C1 毛入园率、大班在园数↑；C2 普惠/公办园占比↑
   质量效果 C5 师幼比、幼师专科以上占比↑；C9 儿童认知/入学准备↑
   远期溢出 C7 母亲就业与工时↑；C6 家庭教育负担率↓；E：C8 理想子女数/二孩生育↑（照实写）
```

**为什么互相支撑**：
1. 需求侧（D1 家庭成本下降）与供给侧（D2 学位与师资扩张）同时成立，排除"只是建了园没人上"或"有人想上没学位"的单边解释。
2. 前轮 A3 主要推供给、主处理 A2 主要降价格、后轮 A1 用中央分档提供外生强度，三类 A 指向同一瓶颈 B，结论不依赖单一政策。
3. C 由近及远：入园（数量）→ 师资与认知（质量）→ 母亲就业与生育（家庭/人口），每一层都以上一层为前提，形成"投资于人"的完整链条。
4. 异质性（财政自给率、中央分担档次、城乡、基期学位缺口）同时检验"钱"路径：财政越弱、中央兜底越重要。

## 10. 全文章节结构（大白话，"幻想中"的全文）

1. **引言**："投资于人"要从娃娃抓起。出生人口下降，幼儿园成片关停，家长又嫌学前贵。部分地方先行免费，2025 年起国家推行学前一年免保教费。我们发现，免费让入园率稳住并上升，幼师队伍更好，妈妈们也能回去上班。
2. **政策背景与理论假说**：画出各地先行免费的时间表和 2025 年中央 80/60/50 分档（分档需核实）。提出两条路：家里花钱少了（钱），幼儿园和老师多了、妈妈时间多了（人）。
3. **研究设计**：县/地市交错 DID，CFPS 个体样本对接区县码；变量定义和数据来源。
4. **基准结果**：免费后入园率、大班在园占比上升（R1、R2）；事件研究前期系数平坦；换估计量、安慰剂放附录。
5. **机制一：钱**：家庭学前支出下降，地方学前投入占比上升（R3、R4）。
6. **机制二：人与供给**：普惠园、公办园占比上升，学位供给扩张（R5）。
7. **异质性**：农村、财政紧张、基期学位缺口大的地区更明显；民办园是被挤出还是转成普惠，照实写（R6、R7）。
8. **进一步一：质量**：师幼比改善、幼师学历提升，孩子认知测验得分提高（R8、R9）。
9. **进一步二：家庭**：有 3—6 岁孩子的妈妈就业和工时上升，没有老人帮带的家庭更明显；家庭教育负担下降（R10、R11）。
10. **进一步三：扩 A 与人口**：三期行动计划（前轮）和 2025 年全国免费（后轮）方向一致，中央分担越高落实越好；生育意愿有所提高，结果照实报（R12—R14）。结论与政策建议收尾。

## 11. 政策建议（大白话）

1. **把免费从一年逐步延伸到三年**（对应第 4 节基准）：免费确实把孩子带进了幼儿园。
2. **中央分担向中西部和财政紧张地区倾斜**（对应第 7 节异质性、第 10 节分档）：越穷的地方越靠中央兜底。
3. **免费的同时稳住普惠园和公办学位、提高幼师待遇**（对应第 6 节机制二、第 8 节质量）：别让免费变成"有价无位"或"有位无质"。
4. **把学前免费和托育、育儿补贴、女性就业支持打包**（对应第 9 节家庭、第 10 节生育）：学前免费也是给妈妈松绑的就业政策。
