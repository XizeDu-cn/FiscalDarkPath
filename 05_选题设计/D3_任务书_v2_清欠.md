## 一、主设定（起点设定，可按通用规则 v2.1 调整）

| 项目 | 设定 |
|---|---|
| 冲击 A | **A1：2018 年清理拖欠民营企业中小企业账款专项行动**（2018 年 11 月国务院常务会议部署，国办印发工作方案，**文号需核实**；2019 年底"应付尽付"目标）。论文里统一叫"**清理拖欠民营企业中小企业账款专项行动**"（简称"清欠专项行动"） |
| 处理强度 | **主强度 G**：2015—2017 年"应收账款前五名"中欠款方为政府机关/事业单位/国企/城投的金额 ÷ 应收账款期末余额，三年均值（连续变量，标准化）。欠款方类型**只用名称关键词自动识别**（"人民政府""局""委员会""管理中心""医院""学校""国有""集团有限公司且实控人为国资"可从 CSMAR 关联方/股东库自动匹配、"城投""建设投资""交通投资"等），识别不出的记为非政府。即设计稿的 E2 的自动化版本 |
| 备选强度 G′ | **行业政府需求占比**：2017 年投入产出表中该行业最终使用里"政府消费 + 公共投资"占比（行业层面，现成数据）。只在第 2 天自动检查触发时进主表，否则进稳健性 |
| 政策后 | Post = 2019 年及以后 |
| 参照年 | 事件研究以 **2018 年**为基期（行动 2018 年 11 月启动，2018 年报基本未受影响） |
| 主样本 | A 股**民营**（实控人非国有）、非金融、非 ST 上市公司，**2014—2022 年**。国企样本单独留着做安慰剂 |
| 主模型 | `reghdfe C c.G#c.Post 控制变量, absorb(企业 行业×年份) vce(cluster 企业)` |
| 控制变量 | 规模、杠杆、ROA、上市年限、营收增长、第一大股东持股、两职合一，全部滞后一期 |
| 同期政策 | 2019 年减税降费、留抵退税、民企纾困债券：主回归不另加，稳健性里加"2018 年增值税税负 × Post"控制；疫情：稳健性里剔除 2020 年 |
| **主结果 C** | **C1 应收账款周转天数**（365 × 平均应收账款 ÷ 营业收入，缩尾 1%）。离清欠最近，CSMAR 现成 |
| **备选 C** | **C3 经营现金流**（经营活动现金净流量 ÷ 总资产）。基准表里与 C1 并列报；第 2 天自动检查用它做"备选 C" |

**故事主线（据此排表）**：

> 清欠专项行动后，被政府和国企欠得越多的民企**回款更快、现金更足**；钱回来以后融资约束下降、第二年投资上升（"钱"路径）；同时年报展望段语气更乐观、分析师预测上调（"预期"路径）；民企拿到钱又加快付给上游供应商，三角债沿链条解开（溢出）。

预期方向：G × Post 对 C1 **为负**（周转天数缩短 = 变好），对 C3 **为正**。下文"方向为正"一律指"**朝变好的方向**"。

### 第 2 天自动检查（主表跑完立刻做，自己决定，不等人）

看表 2 加控制那一列 C1 的 G × Post 系数（"方向对" = 负号）：

| 全部反向（C1 为正且 C3 为负） | **照跑完全部表**，不换设定、不补模块；一页纸第一段写清楚"主结果反向"及可能原因（如 2019—2020 疫情、行业结构） |

## 五、怎么写结果（同刊措辞，数字照表）

### 5.1 措辞模板

| 情况 | 写法 |
|---|---|
| p < 0.01 | "在 1% 水平上显著为负，表明清欠专项行动显著缩短了高暴露民企的回款周期" |
| p < 0.1 | "在 10% 水平上显著，表明……"（**照写"显著"**，同刊惯例） |
| 方向对、不显著 | "系数符号符合预期但不显著，说明……的作用存在边界 / 仍有待进一步释放" |
| 方向相反 | 照实报；能在故事里解释就解释，解释不了写"可能的原因是……" |
| 异质性某组显著、另一组不显著 | "**上述效应主要集中在××企业**"，并报组间差异检验 p 值 |
| 国企安慰剂不显著 | "国有企业样本中系数不显著，符合清欠主要惠及民营企业的预期" |
| 机制变量显著 | "这验证了资金回笼 / 融资约束缓解 / 预期改善渠道" |

### 5.2 不越的线（只有这三条）

1. **正文写的每个数字，都能在表里找到。**
2. **不改数据、不删样本去凑显著。** 样本筛选只按第一节写死的规则；第 2 天检查只按写好的那一次备选。
3. **跑过的回归都在正文或附录里。** 第 2 天检查跑的备选也报；异质性切了几刀，表里就列几刀，不显著的组也列。

这三条之外，**都按同刊标准放松**：不做 BH，不算有效样本量，不逐份核验，不因代理不完美而拒用。

政策文号、时间：设计稿标"需核实"的，正文照样标"需核实"，**不自己编**。
