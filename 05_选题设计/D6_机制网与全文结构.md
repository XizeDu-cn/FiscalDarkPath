# 机制网与全文结构：五个选题从"一条链"到"一张网"

> D1—D5 保留不动，是各选题的 A、C 清单和组合库。本文件做两件事：把机制从单链扩成**机制网**；把每个选题想象成一篇完整的文章，用大白话写出各节长什么样。
> 机制网的意思是：多个 A 从不同口子进来，经过多个中间变量（B、D、E…），落到多个 C 上，而且这些路径互相印证。审稿人挑掉一条，其他几条还能撑住。

## 二、通用模板（大白话）

1. **引言**：C 很重要（挂热词）→ 卡在 B 上 → 国家出了 A → 我们发现 A 让 C 变好，还说清了为什么 → 三点贡献。
2. **政策背景与典型事实**：A 是怎么一步步出来的；画几张图，A 前后 C 的走势一看就有变化。
3. **理论分析与假说**：画机制网。假说 1 是 A→C，假说 2—3 是两条主机制，假说 4 是异质性。
4. **研究设计**：数据、变量、DID 公式。
5. **基准回归与稳健性**：主结果，加上平行趋势、安慰剂、换指标、排除同期政策。
6. **机制分析**：机制网里的两三条路径，分别验证。
7. **异质性分析**：谁受益更多。
8. **进一步分析**：C 往外延伸，比如更长远的结果、溢出到别人、成本收益账。
9. **结论与政策建议**：三四条，每条对应一节的发现。

## 三、五个选题的机制网与"幻想中的全文"

> 下面写的是我们希望讲出来的故事，回归结果以实际估计为准；跑出来不支持的路径，就放到"边界"里如实写。

### D1 税收优惠延续 → 企业预期与高质量发展

**机制网**

```
A1 2023年8月集中延续（12—19号）──┐
A2 研发加计扣除100%制度化（7号）──┼─→ B 政策不确定性↓ ─┬─→ D1 管理层预期↑（年报语调、分析师预测）─┐
A3 留抵退税扩围（2022）──────────┘                      ├─→ D2 现金流↑、融资约束↓ ─────────────┼─→ C1 研发、长期投资↑
                                                        └─→ D3 投资期限拉长（长债长投）────────┘   C2 雇佣↑、劳动收入份额↑
                                                                                                  C3 专利质量、TFP↑
                                    E 供应链传递：受益企业 → 上游供应商订单与研发↑（溢出）
```

**为什么可靠**：三个 A 都指向同一个 B（不确定性），可以互相印证；D1 是"信心"路径，D2 是"钱"路径，审稿人很难同时否掉两条。

**幻想中的全文（大白话）**
- **引言**：中央说"稳预期"，企业最怕政策说变就变；以前优惠一年一续，企业不敢投长线；2023 年 8 月国家一口气延到 2027 年，这是一颗定心丸。我们发现，受益越多的企业，研发和长期投资涨得越多。
- **背景**：画一张"优惠到期—延续"时间轴，标出 2017—2023 年的上百份延续文件，"碎步续期"一目了然。
- **基准**：延续后，受益企业研发强度明显上升；平行趋势、安慰剂（拿不受益的税种当假冲击）都过关。
- **机制一，信心**：年报里"未来""长期""扩张"这类词变多，分析师上调盈利预测。
- **机制二，钱**：现金流更宽裕，长期借款更多，"短债长投"减少。
- **异质性**：小微和民营企业更明显，高度依赖优惠的企业更明显，数字化程度高的企业更明显。
- **进一步**：专利质量更高、TFP 更高；还带动了上游供应商（供应链溢出）；最后算一笔账：每 1 元税收优惠，因为"确定性"多撬动了多少研发。
- **政策建议**：① 把到期又延续的优惠改成长期制度，推进税收法定；② 优惠到期前提前宣告；③ 向小微民企倾斜；④ 建立政策延续的预期管理机制。

### D2 营改增与增值税五五分成 → 地方"投资于人"

**机制网**

```
A1 2016全面营改增 ─────┐
A2 增值税五五分成 ─────┼─→ B 地方自主财力↑ ─┬─→ D1 财政自给率↑ ───┬─→ C1 教育、卫生、社保支出占比↑
A3 2019增值税降率+返还 ─┘  （机械增收强度）    ├─→ D2 "三保"压力↓ ────┤   C2 生均教育经费、每千人医生床位↑
                                              └─→ D3 土地出让依赖↓ ──┘   C3 人口流入、人力资本↑
                                 E 税源培育激励：分成越多，越重视招商引税 → 产业升级 → 再循环到民生
```

**为什么可靠**：D1、D2 是"财力"路径，D3 是"激励"路径；C 从"花钱"（支出占比）到"效果"（生均经费）再到"结果"（人口流入），一路递进。

**幻想中的全文（大白话）**
- **引言**：十五五提出"投资于物和投资于人紧密结合""增加地方自主财力"；地方没钱，民生欠账；2016 年营改增加五五分成，等于重新分了一次钱。我们发现，分成补偿越多的城市，"投资于人"的支出涨得越快。
- **背景**：营改增三步走；画图展示各地增值税依赖度的差异。
- **基准**：机械增收强度每提高 1 个标准差，民生支出占比上升若干个百分点。
- **机制一，财力**：自给率提高，"三保"压力缓解。
- **机制二，激励**：卖地依赖下降，从"投资于物"转向"投资于人"。
- **异质性**：中西部更明显，财政压力大的地方更明显。
- **进一步**：生均经费、医生床位改善，人口流入增加；周边城市也被带动。
- **政策建议**：① 稳定并适度提高地方共享税分享比例；② 共享税分配与民生支出挂钩；③ 减少对土地出让的依赖；④ 对中西部加大转移支付。

### D3 清欠行动 → 民营经济信心

**机制网**

```
A1 2018—2019清欠专项行动 ──┐
A2 2020《保障中小企业款项支付条例》 ─┼─→ B 政府拖欠↓ ─┬─→ D1 应收账款回款加快 ──┬─→ C1 民企预期↑（年报语调）
A3 2024—2025新一轮清欠＋化债资金 ─┘                 ├─→ D2 经营现金流↑ ───────┤   C2 投资、研发、雇佣↑
                                                    └─→ D3 融资约束↓、利息↓ ───┘   C3 民间投资、新设民企↑
                      E 链式传递：民企拿到钱 → 加快付给自己的供应商（商业信用修复，三角债解开）
```

**为什么可靠**：三轮政策、三套暴露度（政府客户占比、应收政府账款、政府采购中标）可以互相替换；D1→D2→D3 是一条会计上就成立的链；E 的"链式还钱"是个很漂亮的进一步分析。

**幻想中的全文（大白话）**
- **引言**：民企信心不足，一个暗伤是政府欠钱不还；国家三轮清欠，还出了条例和《民营经济促进法》；我们发现，被政府欠得越多的民企，清欠后信心和投资回升越多。
- **背景**：画图看上市民企应收政府账款的变化。
- **基准**：清欠后，高暴露民企的回款周期明显缩短。
- **机制**：现金流改善 → 融资约束缓解 → 投资增加。
- **异质性**：中小企业、财政压力大的地区、政府客户占比高的企业更明显。
- **进一步**：年报语调变好（信心）；民企也加快了给供应商付款，三角债被解开；地区新设民企增加。
- **政策建议**：① 建立政府付款的长效机制和失信惩戒；② 把清欠纳入地方考核；③ 化债和清欠联动；④ 政府付款信息公开。

### D4 学前免费 → 学前普及与"投资于人"

**机制网**

```
A1 地方先行免费学前教育（分批）─┐
A2 2025学前一年免保教费（中央80/60/50分档）─┼─→ B 家庭教育成本↓ ─┬─→ D1 入园意愿↑ ─────┬─→ C1 入园率、在园人数↑
A3 学前教育三期行动计划（2010起）─┘                              ├─→ D2 普惠/公办园供给↑ ─┤   C2 幼师数量与学历↑
                                                                  └─→ D3 家庭时间释放 ────┘   C3 母亲就业↑、儿童认知↑
                                  E 远期：育儿成本↓ → 生育意愿↑（投资于人 × 生育支持）
```

**为什么可靠**：需求侧（D1）和供给侧（D2）两条路同时成立；C 从"入学"到"质量"再到"家庭"，层层外扩。

**幻想中的全文（大白话）**
- **引言**："投资于人"要从娃娃抓起；在园幼儿一年少了几百万，幼儿园成片关停；国家开始免费。我们发现，免费让入园率稳住了，还让妈妈们能回去上班。
- **背景**：各地先行免费的时间表；中央分担的分档。
- **基准**：免费后入园率上升，中央分担比例越高的地区越明显。
- **机制**：家庭负担下降（需求）、普惠园增加（供给）。
- **异质性**：农村更明显，财政紧张的地区靠中央兜底效果更明显。
- **进一步**：幼师学历提高；母亲就业增加；生育意愿提高。
- **政策建议**：① 逐步把免费延伸到三年；② 中央分担向中西部倾斜；③ 稳住普惠园供给；④ 学前教育和育儿补贴协同。

### D5 基础养老金与新农保 → 老有所养

**机制网**

```
A1 新农保分县试点（2009—2012）─┐
A2 基础养老金历次提标（2014、2018、2024、2025）─┼─→ B 老人稳定收入↑ ─┬─→ D1 流动性约束↓ ────┬─→ C1 收入↑、贫困↓
A3 各省加发、高龄津贴（强度）─┘                                    ├─→ D2 子女负担↓（转移↓，照实写）─┤   C2 消费↑、营养↑
                                                                    └─→ D3 就医可及↑ ───────┘   C3 抑郁↓、自评健康↑、幸福感↑
                               E 家庭溢出：子女负担减轻 → 子女外出务工、孙辈教育投入↑
```

**为什么可靠**：用"补贴强度"做连续处理，比"有没有新农保"更新；子女转移下降这一项，正好解释成"减负"，把可能的负面结果变成故事的一环。

**幻想中的全文（大白话）**
- **引言**：社保要"可持续"，更要"老有所养"；国家给农民发养老金，十几年里一次次加码。我们发现，加码越多的地方，老人越不穷、越敢花钱、心情越好。
- **背景**：画出历次提标和各省加发的时间线。
- **基准**：提标强度越高，老人贫困率下降越多。
- **机制**：手头宽裕了；不用再向子女伸手；更敢去看病。
- **异质性**：高龄、独居、中西部老人更明显。
- **进一步**：子女更敢外出打工，孙辈教育投入增加（一代养老，三代受益）；算一笔账，每 1 元养老金带来多少福祉。
- **政策建议**：① 建立基础养老金的正常调整机制；② 中央补助向中西部和高龄老人倾斜；③ 养老金与医疗、照护政策协同；④ 发挥社保"投资于人"的功能。

## 四、怎么扩充 D1—D5 的组合库

- **A 从一个扩成三个**：主政策，加前一轮或后一轮政策，再加配套政策。三者在背景一节串成"政策链"，基准用主 A，其余两个作稳健性或进一步分析。
- **C 从一个扩成三层**：直接结果（花钱、数量）→ 质量或效果 → 远期或溢出。分别对应基准、机制或进一步分析。
- **中间变量至少两类**：一条"钱"的路径（财力、现金流），一条"人"的路径（预期、激励、行为），这样机制网才有交叉支撑。
- **全跑清单**照 `D0_C家族法_仿余明桂结构.md` 第二节办：事先写定、全部报告，正文放离 A 最近的 C。
