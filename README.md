# FiscalDarkPath

财政学露骨真相揭穿以及成魔之路发掘。

扒近年财政学、经济学期刊里大量出现的 AI 类、冲击回归类文章：看它们的结论从哪来、热词怎么挂、哪里是八股、哪里藏手脚，并从中反推好讲故事的选题。

> 本项目里的"套路""包装""卖药"，指写作与论证层面的做法（测到了什么 vs 说成了什么），不涉及对数据真实性或学术不端的指控。文中数字均取自原文表图，标了页码可查。

## 目录结构

```
00_核心结论/        提炼后的结论，最常看的都在这里
01_单篇拆解/        单篇文章逐段大白话拆解
02_批量检验/        批量文章的统计与假说检验
  └ 数据/           编码表（CSV）与编码协议
03_阅读笔记/        早期读书笔记
04_参考模板/        拆解写法的参考样例
05_选题设计/        选定选题的完整设计稿（A、C、组合、机制链）
papers/            论文原文 PDF，按批次存放
```

## 新增内容放哪

- 新的单篇拆解 → `01_单篇拆解/`，命名"第一作者等年份_短题名_拆解.md"
- 新的批量统计或检验 → `02_批量检验/`，编码表放 `数据/`
- 结论有更新 → 直接改 `00_核心结论/` 对应文件，不另开新文件
- 新一批原文 → `papers/` 下新建"编号_批次名"文件夹
